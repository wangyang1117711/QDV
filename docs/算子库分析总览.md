# 算子库对比分析 — 总览

> 任务：对比 QDV 当前算子库与海康威视 MVS/VM 算子库，输出对比分析报告 + 改进报告。

## 核心发现
- **QDV 已实现 55 个可用算子**（10 大类，OpenCV 驱动），覆盖 VM 核心算子约 **70%**。
- **3 个幻影算子**（`Reconstruct3D`/`BinocularDisparity`/`SurfaceMatching`）仅元数据、无实现，运行时 `createTool` 返回 `nullptr` —— 最紧迫崩溃风险。
- **工业刚需算子缺失**：位置修正 PositionCorrect、单位换算 UnitConvert、卡尺 Caliper、光源控制 LightControl、脚本/循环、端到端 OCR（DLOCR）等。
- **标定闭环不完整**：有真实手眼标定 `HandEyeCalib`，但无相机内参标定与下游单位换算算子。
- **QDV 亮点**：元数据外部化（`operators.json`）、数据驱动表单、`Result<T>` 错误模型、SQLite 持久化、细粒度预处理/形态学/分割。
- **核实状态（2026-07-15）**：对标海康 MVS/VM 的能力清单已据公开来源交叉核实，原 20 个 `(推断)` 算子全部确认为真实能力，故上述"QDV 缺失项"为**已核实的真实差距**；仅 4 处子项存疑（双边滤波、独立 Clip 裁剪、Lua 脚本语言、部分数值默认值），不改变优先级结论。

## 优先级速记
- **P0（止血+刚需）**：清幻影算子、PositionCorrect、UnitConvert、Caliper、CameraCalib、匹配/识别补全
- **P1（健壮）**：失败语义修正、元数据一致性校验、类型化端口、流程控制、缺陷算子
- **P2（性能）**：DL 真实化+GPU、尺度/亚像素、并行、OpenCV 优化、通信算子化
