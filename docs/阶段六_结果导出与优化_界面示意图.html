4. InferenceCache 推理结果缓存流程（Task 15.2）

集成于 ZeroShotDetectTool::execute()，同图同参数重复执行场景显著加速。

execute(input)
→
计算缓存键
SHA-256(图)+提示词+
SHA-256(ROI)+模型类型+路径
→
lookup()
→
命中 ✓
直接返回缓存结果
未命中 ✗
zsu::Kit::infer()
未命中路径：infer → insert(写入缓存) → 返回  |  命中路径：直接返回（跳过推理）

缓存键与值结构

维度实现说明
图像哈希cv::imencode(".jpg") + QCryptographicHash::Sha256JPG 编码比 PNG 快，对缓存键稳定性足够
提示词原串拼接（如 "scratch . dent"）提示词变化即视为不同输入
ROI 哈希QJsonObject::fromVariantMap(roi) → SHA-256矩形/多边形 ROI 均覆盖
模型类型+路径原串拼接模型切换/重训后自动失效
缓存值ToolResult（含 data/ports/score/overlayImage）完整结果，命中时直接复用
容量策略QCache LRU，默认 100 条超限自动淘汰最旧条目
线程安全QMutex 互斥方案并行执行时安全
统计hitCount()/missCount()缓存命中率监控
与现有 ::InferenceCache（include/AI/）的关系： 两者命名空间不同（新类在 QDV::，旧类在全局作用域），可共存。
新类按 spec 要求：
① 缓存键含提示词 + ROI 哈希（旧类不含）；
② 缓存值是 ToolResult（旧类是 QJsonObject），便于在 ZeroShotDetectTool::execute 直接复用；
③ 单例模式 + 默认 100 条（旧类非单例，默认 50 条）。
