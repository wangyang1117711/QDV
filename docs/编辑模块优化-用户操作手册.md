# 编辑模块优化 —— 用户操作手册

> 适用范围：QDV 视觉检测系统的图形化方案编辑模块（画布）。
> 本文档对应的功能为「输出项配置增强 / 多连接管理 / 输入输出冲突处理 / 智能算子推荐」。
> 版本：2.x（spec：editor-output-connection-optimization）

---

## 一、功能总览

本版编辑模块在原有「拖拽算子 → 连线 → 调参 → 运行」的基础上，新增四类能力：

| 功能 | 解决的问题 | 入口 |
| --- | --- | --- |
| **节点输出项配置** | 一个算子可输出多个结果（如分类算子的类别、类别名、置信度），可只选用需要的输出项 | 双击节点 → 「输出参数设置」区 |
| **多连接管理** | 一个输入端口可接入多个上游、一个输出端口可被多个下游消费，连线多了需要统一查看/筛选/删除 | 工具栏「连」按钮 |
| **输入/输出冲突处理** | 同名输出、类型不兼容、多输入歧义等会导致运行结果不确定，需要指定「主方案」消除冲突 | 工具栏「冲」按钮（带红色角标） |
| **智能算子推荐** | 选中算子后，推荐最合适的下一个算子，一键添加并自动连线 | 画布右上角「智能推荐」面板 |

## 二、配置节点输出项

### 2.1 打开输出项配置

1. 在画布上 **双击** 任意节点，打开「参数编辑器」弹窗。
2. 向下滚动到 **「输出参数设置」** 分组（默认折叠，标题旁有 `▶/▼` 箭头，点击可展开/折叠）。
3. 仅当该算子确实存在多个输出项时，此区域才会显示。

### 2.2 勾选 / 取消输出项

- 每个输出项左侧有一个 **复选框**，勾选表示「启用并输出该结果」，取消勾选表示「禁用该输出」。
- 输出项行显示信息：**别名（优先级显示）**、类型名（如 `Image`、`String`）、一行简短描述。
- 输出项默认启停由算子自身决定（单目标必填项默认启用，多目标专属项默认停用）。
- **改动即时生效且可撤销**：每次勾选都会写入方案，可通过工具栏的「撤销」恢复。

> 提示：取消勾选某个输出项后，引用它的连线会被视为「引用了已禁用的输出」，后续建连会提示错误。

### 2.3 搜索与筛选

在输出项列表上方提供三种辅助手段：

- **关键字搜索框**：输入关键字（可匹配输出项名称、中文名、别名、类型、描述），实时过滤。
- **分组下拉框**：按输出项的分组名过滤（如按类型分组），首项为「全部分组」。
- **状态过滤按钮**：`全部 / 仅启用 / 仅禁用`，只看某类状态的输出项。

### 2.4 批量启用 / 禁用

- 列表顶部右侧有 **「全选」**、**「全不选」** 按钮，一键启用 / 禁用该节点的全部输出项。
- 每个分组的标题右侧有 **「快速」** 文字，点击可「仅启用该分组下的所有输出项」。

## 三、查看与管理多连接

### 3.1 打开连接管理面板

点击编辑器顶部工具栏的 **「连」** 按钮，弹出「连接管理」面板。

### 3.2 查看与筛选

- 面板按「源节点.输出端口 → 目标节点.输入端口」逐条列出当前方案的全部连线。
- 顶部显示「已显示条数 / 总条数」。
- 在顶部 **筛选输入框** 中输入关键字，可按 **源/目标节点名、端口名** 实时过滤（匹配节点类型名或端口名）。

### 3.3 删除某条连接

- 每条连接行右侧有 **「✕」** 按钮，点击后删除该条连线。
- 删除操作 **可撤销**（走撤销栈），删除后顶部会弹出「已删除连接」提示。

### 3.4 关于多连接

- 本模块支持「一输入多上游」与「一输出多下游」。
- 画布上连线会自动做**分层与交叉避让**，便于查看多条连接。
- 如需删除，也可直接在画布上选中连线后删除，或在本面板统一管理。

## 四、处理输入/输出冲突

### 4.1 冲突类型

系统会自动检测三类冲突，并在工具栏「冲」按钮上显示**红色角标（数字）**：

| 冲突类型 | 含义 | 示例 |
| --- | --- | --- |
| **同名冲突（dupAlias）** | 同一节点多个输出端口别名相同，无法区分 | 两个输出项都叫「结果」 |
| **类型不兼容（typeMismatch）** | 上游输出端口类型与下游输入端口类型不兼容 | `String → Image` 的连线 |
| **多输入绑定歧义（multiInputAmbiguity）** | 某下游输入端口被多个上游绑定，且类型能力冲突或输出别名相同，无法明确取哪个 | 一个输入接了多个不同来源 |

### 4.2 打开冲突面板

点击工具栏 **「冲」** 按钮（或红色角标），弹出「输入/输出冲突」面板。

### 4.3 勾选并指定主方案

- 面板按冲突类型分组展示（各自带有颜色标识：同名-黄、类型不兼容-红、多输入歧义-橙）。
- 每条冲突显示：**冲突描述**、**节点与端口**、以及一组 **候选（candidates）**。
- 在候选列表中 **勾选一个**作为「主方案」（同一冲突内为单选，勾选新项会自动取消旧项）。

### 4.4 应用并消除冲突

点击底部 **「应用」** 按钮，系统按冲突类型自动处理：

| 冲突类型 | 应用时的处理 |
| --- | --- |
| 同名冲突 | 勾选端口 → 启用；同组其他候选端口 → 禁用（可撤销写回输出配置） |
| 多输入歧义 | 保留勾选的上游绑定，删除其余候选绑定（走断开连接，可撤销） |
| 类型不兼容 | 删除该条不兼容连接（走断开连接，可撤销） |

- 应用成功后弹出「已消除 N 处冲突」提示。
- 若全部冲突解决，工具栏角标消失；空态显示「未检测到冲突」。

> 注意：以上操作均 **可撤销**，可放心操作。若某条冲突你不想处理，保持不勾选即可，应用时会被跳过。

## 五、使用算子推荐

### 5.1 查看推荐

- 「智能推荐」面板常驻在 **画布右上角**（可点击标题栏 `▢/▣` 折叠/展开）。
- **在画布上选中一个算子节点**，面板自动给出 **Top3 推荐算子**。
- 每个推荐项显示：**算子描述**、**置信度百分比**、**推荐理由**（如「端口类型兼容（输出 X 可被消费）」「常作为当前算子下游」「最近/常用算子」），按置信度降序排列。
- 未选中节点时提示「选中算子以查看推荐」。

### 5.2 一键添加并自动连线

- **点击任意推荐项**，系统会在选中节点**右侧**新建该算子的节点，并**自动建立一条连线**（选中节点 `output` → 新节点 `input`）。
- 新建节点与连线均 **可撤销**。

### 5.3 最近使用 Tab

- 面板顶部有 **「推荐」/「最近使用」** 两个标签页。
- 切到「最近使用」，展示最近使用过的算子（排除当前节点自身），同样可按置信度排序、点击一键添加。

### 5.4 调整推荐权重

- 面板底部「权重调整」区提供三个滑杆：**类型兼容 / 方案结构 / 使用频率**。
- 调整滑杆会 **实时刷新推荐结果**，并 **持久化**到 `config/recommender.json`（下次启动保留）。

## 六、常见问题（FAQ）

**Q1：为什么有些算子没有「输出参数设置」区？**
A：只有元数据中声明了多个输出项的算子才有此配置区。单输出或未声明输出的算子不显示。

**Q2：我取消勾选了一个输出项，建连却报错？**
A：确实如此。被禁用的输出项不能被引用为连接源。请先在节点编辑器中重新勾选该输出项，或在冲突面板中处理。

**Q3：冲突角标一直显示，但我没看到问题？**
A：角标数字 = 当前检测到的冲突总数。打开「冲」面板查看具体冲突与位置；若某条确属误报，可保持不勾选并关闭即可。

**Q4：一键添加的推荐算子在侧面，位置不理想，能移动吗？**
A：可以。推荐添加的节点支持正常拖拽移动（选中后拖动），移动会记录进撤销栈。

**Q5：推荐的依据是什么？**
A：综合三方面打分：端口类型兼容性、该算子作为当前算子下游的统计频次、全局使用频率与最近使用记录。三者权重可调（见 5.4）。

**Q6：调整权重会影响其他人的方案吗？**
A：不会。权重保存在本机的 `config/recommender.json`（可执行程序目录下），仅影响本机推荐结果。

**Q7：误删了连接或输出配置，能恢复吗？**
A：能。本模块的所有删除/配置变更均走撤销栈，可多次使用工具栏「撤销」逐步恢复。
