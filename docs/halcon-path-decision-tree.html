四类叶子节点详情与主报告章节对照

叶子 A · 路径 A - 原生 SDK 直接推理

一句话总结：QDV 进程内嵌 Halcon C++ SDK，直接加载 .hdl 模型推理，不转换格式，需 Halcon 运行时授权。

投入：6.5 人·周 + $5K-$8K/年/席位许可 延迟：1.2-1.8x GPU / 5-10x CPU 侵入性：中侵入 可行性：有限可行，不推荐作为首期主路径
→ 主报告：Halcon模型集成方案评估报告.md §3 三条候选技术路径详述（路径 A）

叶子 B · 路径 B - 离线 ONNX 转换 ★ 推荐首期 P0

一句话总结：Halcon 训练环境一次性将 .hdl 导出为 .onnx，QDV 复用现有 ONNX 推理链路，零 SDK 依赖。

投入：3.0 人·周 / 4-5 自然周 许可：$5K-$8K/年（仅训练环境） 延迟：1.0x（与 ONNX 基线持平） 侵入性：零侵入（对既有 ONNX 链路） ROI：中
→ 主报告：Halcon模型集成方案评估报告.md §3 三条候选技术路径详述（路径 B）

叶子 C · 路径 C - 运行时桥接适配 ★ 推荐二期 P1

一句话总结：路径 B 的运行时封装版，用户选"Halcon 模型"类别指向 .hdl 文件，QDV 内部自动转换+缓存+算子适配，强依赖路径 B。

投入：路径 C 增量 14.5 人·周 / B+C 组合 17.5 人·周 / 16-20 自然周 延迟：1.0x（转换后复用现有后端） 侵入性：低侵入（UI 类别扩展 + 算子层适配） ROI：中
→ 主报告：Halcon模型集成方案评估报告.md §3 三条候选技术路径详述（路径 C）

叶子 D · 暂不实施

一句话总结：当前条件不满足实施前提（无 Halcon 授权预算 / 无 Halcon 训练环境 / ONNX 导出能力未验证），建议持续关注 Halcon ONNX 导出能力官方确认。

触发条件：D2=否 且 D1=是（需原生推理但无授权预算） 动作：持续关注官方文档与版本更新
