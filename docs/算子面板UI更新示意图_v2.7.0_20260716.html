5. 海康VM算子对齐对照表
海康VM算子QDV对应实现对齐状态说明
全局变量自定义工具VariableManager + VariableTool(define)已对齐支持7种类型: int/double/string/bool/roi/region/points
变量读算子VariableTool(get)已对齐从全局变量管理器读取变量值
变量写算子VariableTool(set)已对齐写入全局变量管理器
逻辑运算 ANDBranchControlTool(AND)已对齐多输入逻辑与
逻辑运算 ORBranchControlTool(OR)已对齐多输入逻辑或
逻辑运算 NOTBranchControlTool(NOT)已对齐单输入逻辑非
逻辑运算 XORBranchControlTool(XOR)已对齐双输入逻辑异或
条件分支BranchControlTool(比较运算)已对齐6种比较: >/</==/!=/>=/<=
多分支选择 switchBranchControlTool(switch)已对齐switchValue + branchCases 映射
流程合并/等待FlowJoinTool已对齐等待并行分支完成，支持超时
循环遍历(网格)LoopTool(grid)已对齐gridCols × gridRows 网格切片
循环遍历(列表)LoopTool(list)已对齐自定义ROI列表遍历
循环遍历(检测)LoopTool(detection)已对齐基于检测结果遍历
计数循环LoopTool(count)已对齐固定次数循环
条件循环LoopTool(while)已对齐whileCondition 为真时继续
自定义算子封装Scheme 子链 + ToolFactory已对齐子链算子序列封装为可复用单元
