图像预处理 ImagePreprocess ×

核心含义

coreMeaning
对输入图像执行滤波、锐化、形态学等预处理操作，抑制噪声、增强特征，为后续检测/识别提供更稳定的图像输入。

适用场景

useCase
适用于图像存在噪声、光照不均、对比度不足或需要形态学开闭运算的场景；常作为 ReadImage 之后、特征提取之前的标准前置步骤。

功能描述

description
支持 5 类操作：高斯滤波、均值滤波、中值滤波、拉普拉斯锐化、形态学（腐蚀/膨胀/开/闭）。形态学操作可配置 kernelSize 控制结构元素大小。

参数详解

params
operation · 操作类型 Enum
默认: gaussian|可选: gaussian/mean/median/sharpen/morphology
选择预处理算法。gaussian 抑制高斯噪声，median 抑制椒盐噪声，morphology 执行形态学操作。
kernelSize · 核大小 Int
默认: 3|范围: [1, 31]
滤波/形态学核的边长（奇数）。仅在 morphology ≠ none 时显示。
morphology · 形态学类型 Enum
默认: none|可选: none/erode/dilate/open/close
形态学操作类型。none 表示不执行形态学，此时 kernelSize 自动隐藏。

注意事项

notes
kernelSize 必须为奇数；中值滤波对大核较慢；形态学操作会改变区域面积，需谨慎选择操作方向。

关联算子

relatedOps
读取图像 颜色空间转换 线圆检测 Blob 分析

参数名 类型 默认值 help 字段内容
operation Enum gaussian 选择预处理算法。gaussian 抑制高斯噪声，median 抑制椒盐噪声，morphology 执行形态学操作。
kernelSize Int 3 滤波/形态学核的边长（必须为奇数）。仅在 morphology ≠ none 时显示。范围 [1, 31]。
morphology Enum none 形态学操作类型。none 表示不执行形态学，此时 kernelSize 自动隐藏。可选 erode/dilate/open/close。
inPlace Bool true 是否直接覆盖输入图像变量。关闭则保留原图，输出到新变量。
strength Float 1.0 滤波强度系数，仅对 sharpen 操作生效。值越大锐化效果越明显，推荐范围 [0.5, 3.0]。
说明：本示意图为静态 HTML，通过 CSS :hover 模拟 QML 中的 tooltip 交互。 实际运行时，三种帮助形式由 OperatorHelpProvider（C++ 单例）统一提供数据， 通过 editViewBridge 暴露给 QML：getShortDesc(type) / getOperatorDoc(type) / getParamHelp(type, paramName)。 参数 tooltip 在 ParamForm.qml 中通过 paramHelpIconComp inline Component 实现，width 240px、wrapMode WordWrap、最长 200 字符截断、delay 200ms、timeout 10000ms。
