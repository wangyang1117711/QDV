## v2.1.0 (2026-06-04) — UI 升级 M3 + M4 + 训练后端端到端可用

### 🎉 新功能

#### 1. Python 训练后端落地
- **目录**：`training/`（PyTorch 2.1.2+cpu + albumentations 1.3.x + ONNX 导出）
- **入口**：`training/train.py`（CLI：--config / --output_dir）
- **桥梁**：`QDV::TrainingBridge`（`include/AI/TrainingBridge.h` / `src/AI/TrainingBridge.cpp`）
  - QProcess 启动 `python train.py` 并行 JSON Lines 进度协议
  - 数据集清单生成（分层抽样 train/val split）
  - 进度/完成/错误三类信号：`trainingProgress / trainingCompleted / trainingError / logOutput`
  - **30s 心跳监控**：区分"启动后无任何输出"与"训练中卡死"，超时强制 `kill()` 进程
  - **complete 信号去重**：通过 `m_completedEmitted` 标志避免"完成"与"异常退出"重复弹窗
  - **训练完成自动注册**：`ModelManager::registerTrainedModel` 将新 ONNX + labels 拷入 `models/`，更新 `manifest.json`，命名冲突自动加时间戳

#### 2. 训练进度对话框与日志面板
- 训练中显示「Epoch X/Y · Train Acc · Val Acc · Elapsed」
- 控制台日志面板（`m_consoleLog`）实时显示 Python stdout/stderr
- 失败时区分阶段（load_config / data / dataloader / training）提供明确提示

## v2.0.0 (2026-05-30)

### 🎉 新功能

#### 1. 图像列表功能增强
- **文件**：`TrainingInferenceView.cpp`
- **功能**：每个图像项左侧添加独立复选框
- **特点**：
  - 支持单个选择/取消选择
  - 复选框状态与数据模型实时同步
  - 性能优化：状态更新不重建整个列表

#### 2. 图片选择功能实现
- **文件**：`TrainingInferenceView.cpp`
- **功能**：
  - ✅ 全选/取消全选按钮
  - ✅ 反选功能按钮
  - ✅ 显示已选数量（如：已选: 2/5）
  - ✅ 选择状态在滚动、加载时保持稳定

#### 3. 类别管理功能优化
- **文件**：`CategoryPanel.cpp`
- **功能**：
  - ✅ 每个类别名称右侧添加"加入"按钮

  - ✅ 点击按钮将选中图片添加到对应类别
  - ✅ 提供操作成功/失败的视觉反馈

#### 4. 模型选择功能配置
- **文件**：
  - `ModelManager.h` / `ModelManager.cpp`
  - `InferencePanel.cpp`
- **功能**：
  - ✅ 默认模型名称从"默认模型"改为"YOLO"
  - ✅ 模型列表：yolov5s、resnet50、defect_detector
