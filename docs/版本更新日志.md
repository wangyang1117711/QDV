## v2.5.0 (2026-07-06) — 编辑模块新功能（连接线删除 / Halcon预览 / 整链部署 / 单算子运行）

### 🎉 新功能

#### 1. 连接线删除交互
- **操作**：鼠标悬停连线高亮红色（3px）→ 左键直接删除 / 右键弹出确认菜单
- **命中检测**：三次贝塞尔曲线采样 20 点离散化为 19 段线段，鼠标点到线段最短距离 < 8px 视为命中
- **事件穿透**：连线 MouseArea 使用 `propagateComposedEvents: true` + `mouse.accepted = false`，未命中时事件穿透到下层节点
- **撤销支持**：删除连线通过 `DisconnectNodesCommand` 推入 QUndoStack，支持 Ctrl+Z 撤销

#### 2. Halcon 风格图像预览（ImageViewer.qml）
| 操作 | 效果 |
|------|------|
| 滚轮上滚 | 以鼠标为中心放大（×1.15，上限 20×） |
| 滚轮下滚 | 以鼠标为中心缩小（÷1.15，下限 0.1×） |
| 左键拖拽 | 平移图像（光标变 ClosedHandCursor） |
| 右键点击 | 重置为"适应窗口"模式 |
| 工具栏"适应窗口" | 计算最佳缩放使图像完整显示并居中 |
| 工具栏"1:1" | 重置为原始尺寸 100% |

- **缩放数学原理**：以鼠标为中心缩放时，保持鼠标点对应的图像坐标不变（新 offset = 鼠标坐标 − 图像坐标 × 新缩放）
- `DeployDialog.qml` 模态对话框内嵌 ImageViewer，支持部署完成后缩放/平移浏览

#### 3. 整链部署
- **入口**：顶栏「▶ 部署」按钮 → FileDialog 选择输入图像（PNG/JPG/BMP/TIFF）
- **流程**：`EditViewBridge::runScheme(inputImagePath)` → cv::imread 加载 → buildToolChainFromNodes → ToolChainExecutor.execute → saveMatToTempPng → 返回结果
- **DeployDialog 模态对话框**：顶部摘要（成功/失败/总耗时）+ 算子执行明细 ListView + 输出图像预览 + 底部「查看大图」/「关闭」
- **相机接口预留**：`setCameraFrame(path)` 设置临时帧，`runScheme("")` 自动使用

#### 4. 单算子运行
- **入口**：节点右键菜单「▶ 运行到此算子」/ 算子编辑器「▶ 运行」按钮
- **上游链拓扑排序**：DFS 递归收集上游节点，返回节点 ID 列表按拓扑有序（最上游在前，目标节点在最后）
- **后端**：`EditViewBridge::runSingleOperator(nodeId, inputImagePath)`，返回 `{success, upstreamCount, elapsedMs, outputImagePath, upstreamResults, targetResult}`
- **使用场景**：调试单个算子、参数调优、问题定位

#### 5. 算子参数编辑器运行按钮
- 双击算子节点打开 OperatorEditorDialog → 调整参数 → 点击「▶ 运行」→ 先应用参数 → 选择输入图像 → 执行 runSingleOperator（含上游链）
- 与右键菜单区别：编辑器按钮先应用编辑器中的参数，再运行
