1. 文档概述

1.1 文档目的

本文档旨在为QDetectVision（奇测视觉检测系统）的用户提供完整、专业、详细的操作指南，帮助用户快速理解系统架构、掌握操作技能、解决实际问题，确保系统在工业生产环境中的稳定、高效运行。

📋 文档目标读者
  • 产线操作员：日常检测任务执行、结果查看、异常报警处理
  • 工艺工程师：检测方案制定、视觉工具链配置、参数调优

  • 系统管理员：用户账号管理、系统初始化配置

2. 程序简介

2.1 功能概述

QDetectVision是一款基于机器视觉的工业检测软件，提供完整的视觉检测解决方案。

📷 图像采集

支持工业相机实时采集、本地图片导入、批量图片处理

🛠️ 视觉工具链

提供13+种视觉检测工具，支持灵活编排检测流程

📋 方案管理

支持检测方案的创建、保存、加载、版本管理

📡 结果输出

支持TCP/串口通信、IO信号输出、FTP上传

📊 实时监控

提供检测结果统计、异常报警和运行状态监控

🤖 AI集成

支持深度学习模型推理（ONNX Runtime）

项目最低要求推荐配置最佳配置
操作系统Windows 10 64位Windows 10/11 64位Windows 11 64位
处理器Intel Core i5 第8代Intel Core i7 第11代+Intel Core i9 第12代+
内存8 GB16 GB+32 GB+

2.3 安装说明

1
准备安装环境

确保目标计算机满足最低运行要求，已安装Visual C++ Redistributable (x64)

前置条件
  • 管理员权限
  • 足够的磁盘空间
  • 关闭杀毒软件临时防护
2
复制程序文件

将程序文件夹完整复制到目标位置，建议路径：D:\QDetectVision\

💡 建议

避免安装在C盘或包含中文路径的目录

3
首次启动配置

以管理员身份运行QDetectVision.exe，系统自动进行初始化配置

4. 界面详解

4.1 登录界面

4.1.1 布局说明

顶部标题区

显示系统名称、版本信息、公司Logo

中心登录区

包含用户名输入框、密码输入框、登录按钮

底部状态栏

显示系统状态、网络连接、版权信息

4.1.2 界面元素组成

元素类型功能说明权限
用户名输入框输入控件输入登录用户名，支持自动完成历史记录所有用户
密码输入框输入控件输入登录密码，支持回车键提交，密码掩码显示所有用户
登录按钮操作按钮点击或按回车键提交登录请求所有用户
锁定状态提示显示组件连续失败后显示剩余锁定时间倒计时所有用户

4.1.3 视觉设计规范

  • 配色方案：主色调蓝色系(#2563eb)，辅助色紫色系(#7c3aed)，背景色白色/深色
  • 字体规范：标题微软雅黑24px Bold，正文微软雅黑14px Regular
  • 间距规范：输入框间距16px，按钮间距12px，边距24px
  • 响应式设计：支持1920×1080、1366×768等常见分辨率，最小支持1024×768

4.1.4 交互反馈机制

  • 成功反馈：登录成功显示绿色成功提示，1秒后自动跳转到主界面
  • 错误反馈：登录失败输入框红色高亮，显示具体错误信息（用户不存在/密码错误/账号锁定）
  • 加载反馈：验证中按钮显示加载动画，禁用重复点击

4.1.5 业务逻辑关联

🔒 登录安全机制
  • 连续5次登录失败后，账号将被锁定15分钟
  • 锁定期间每次尝试会自动延迟（500ms→1s→2s→4s→8s）
  • 程序自动记录所有登录尝试到日志文件（包含时间、IP、结果）
  • 密码使用PBKDF2加密存储，10万次迭代

5. 操作流程

5.1 用户登录流程

📋 前置条件
  • 程序已正确安装并启动
  • 已有有效的用户账号（首次使用需创建管理员账号）
  • 键盘输入设备工作正常
1
启动程序

双击桌面快捷方式或bin目录下的QDetectVision.exe启动程序

✅ 预期结果

程序正常启动，显示登录界面

⚠️ 异常处理
异常情况处理方法
缺少DLL文件安装Visual C++ Redistributable
配置文件损坏删除配置文件夹，程序自动重建
端口被占用检查并关闭占用端口的程序
2
输入用户名

在用户名输入框中输入有效的用户名

💡 提示

支持自动完成历史用户名，使用方向键选择

3
输入密码

在密码输入框中输入对应的密码（密码显示为掩码）

4
提交登录

点击"登录"按钮或按回车键提交登录请求

⚠️ 异常处理
异常情况处理方法
用户不存在检查用户名输入，联系管理员创建账号
密码错误重新输入密码，注意大小写
账号已锁定等待锁定时间结束或联系管理员解锁
5
登录成功

系统验证通过，自动跳转到主界面

✅ 预期结果

显示绿色成功提示，1秒后进入主界面，状态栏显示当前用户信息

5.2 创建检测方案流程

📊 方案创建流程图
登录系统 → 进入方案管理 → 点击新建方案 
↓
输入方案名称 → 选择保存路径 → 确认创建 
↓
进入编辑界面 → 配置相机参数 → 添加检测工具 
↓
配置工具参数 → 连接测试图像 → 运行测试 → 保存方案
📋 前置条件
  • 已成功登录系统
  • 具有工程师或管理员权限
  • 有可用的测试图像或已连接相机
1
进入方案管理

点击左侧导航栏的"方案"按钮，进入方案管理界面

2
点击新建方案

点击顶部工具栏的"新建方案"按钮，弹出新建方案对话框

3
配置方案信息

在对话框中输入方案名称，选择保存路径，填写方案描述

💡 建议

方案名称建议包含产品型号、检测内容，如"产品A-外观检测-v1"

4
确认创建

点击"确认"按钮创建新方案，系统自动进入编辑界面

✅ 预期结果

成功创建方案，自动跳转到编辑界面，方案文件已保存到指定路径

⚠️ 异常处理
异常情况处理方法
路径无权限选择有写入权限的路径，或以管理员身份运行程序
名称已存在修改方案名称，或覆盖已有方案
磁盘空间不足清理磁盘空间，选择其他保存位置

5.3 配置相机流程

📋 前置条件
  • 已创建或打开检测方案
  • 相机已连接到网络并上电
  • 已知相机的IP地址和参数
1
进入相机配置

点击左侧导航栏的"相机"按钮，进入相机配置界面

2
配置连接参数

在左侧参数区输入相机IP地址、端口号、数据包大小等参数

📋 常用参数
  • IP地址：192.168.1.100
  • 端口：3956
  • 数据包：8192字节
3
测试网络连接

点击"测试连接"按钮，验证网络连通性

⚠️ 异常处理
异常情况处理方法
网络不可达检查IP地址、网线连接、相机电源
防火墙阻止添加程序到防火墙白名单
IP冲突修改相机IP地址
4
配置图像参数

设置分辨率、曝光时间、增益、触发模式等图像参数

📋 推荐参数
  • 分辨率：1920×1080（根据实际需求调整）
  • 曝光时间：5000μs（根据环境亮度调整）
  • 增益：1.0（避免过高增益产生噪点）
  • 触发模式：硬件触发（产线环境）或软件触发（测试环境）
5
连接相机

点击"连接"按钮，建立与相机的通信连接

✅ 预期结果

6. 常见问题

6.1 程序启动问题

Q1：程序无法启动，提示缺少DLL文件

原因：缺少Visual C++ Redistributable运行时组件

解决方案：安装Visual C++ Redistributable (x64) 版本

Q2：程序启动后闪退

原因：配置文件损坏或硬件驱动问题

解决方案：删除配置文件夹，程序会自动重建；检查显卡驱动是否正常

6.2 登录问题

Q3：登录失败，提示"用户不存在"

原因：输入的用户名尚未在系统中注册

解决方案：确认用户名输入正确（区分大小写）；联系管理员创建新账号

Q4：登录失败，提示"密码错误"

原因：密码输入错误

解决方案：重新输入密码，注意大小写；忘记密码联系管理员重置

6.3 相机连接问题

Q5：相机连接失败，提示"网络不可达"

原因：IP地址配置错误、网络不通或相机未上电

解决方案：检查IP地址是否正确；使用ping命令测试网络连通性；确认相机电源已接通

Q6：相机连接成功，但画面模糊

原因：相机焦距未调整正确或镜头脏污

解决方案：调整相机焦距；清洁镜头表面；检查相机对焦模式设置

7. 注意事项

7.1 安全提示

  • ⚠️ 密码安全：请使用强度足够的密码，不要使用过于简单的密码
  • ⚠️ 账号管理：初次使用务必创建管理员账号，并妥善保管密码
  • ⚠️ 定期备份：定期导出检测方案文件，防止数据丢失
  • ⚠️ 网络安全：TCP通信建议在内网环境使用，避免直接暴露在公网

7.2 操作注意事项

  • 📌 检测过程中不要关闭相机连接或切换方案
  • 📌 修改工具参数后务必保存方案，否则修改不会持久化
  • 📌 工具链中的工具按顺序执行，前面的工具结果会传递给后续工具
  • 📌 IO线路模式修改后需重新连接才能生效
  • 📌 相机参数调整后建议拍摄多张测试图像验证效果

7.3 性能优化建议

  • 将程序安装在SSD上以提升启动速度
  • 对于高精度检测场景，使用硬件触发模式
  • AI推理任务建议使用NVIDIA GPU加速
  • 合理设置AI模型的置信度阈值和Top-K值
  • 定期清理日志文件，避免占用过多磁盘空间
