# QDetectVision 画布连接线选择与算子复制粘贴使用指南

- 版本：1.0
- 日期：2026-07-10
- 适用对象：使用 QDetectVision 编辑模块的工程师与测试人员

## 一、功能概述

本指南说明编辑画布中两项新增交互：

1. **连接线单独选择与删除**：支持点击或框选方式选中单个连接线，选中后可通过 `Delete` 键或右键菜单删除。
2. **算子节点复制与粘贴**：支持通过快捷键 `Ctrl+C/V` 或右键菜单复制选中算子节点，粘贴时生成保留全部参数和内部连接的新节点副本。

## 二、连接线选择与删除

### 2.1 选中连接线

| 操作 | 说明 |
|------|------|
| **鼠标悬停** | 连接线变为红色高亮，鼠标指针变为手型。 |
| **左键点击** | 连接线进入选中状态，变为**黄色高亮并带发光效果**，同时清空当前节点选中状态。 |
| **右键点击** | 同左键先选中该连线，并弹出右键菜单。 |
| **框选** | 在画布空白处按住左键拖拽形成框选区域，若某条连线的起点或终点落在区域内，则该连线被选中。 |

### 2.2 删除连接线

选中连线后，可通过以下任一方式删除：

- 按键盘 `Delete` 键；
- 右键点击连线，选择"删除连接"。

> **注意**：若同时选中了节点和连线，按 `Delete` 会优先删除节点（节点删除会自动清理相关连线）。按 `Esc` 可一键清空所有选中状态。

### 2.3 取消选择

- 按 `Esc` 键；
- 点击画布空白处；
- 点击节点（节点选中会替代连线选中）。

## 三、算子节点复制与粘贴

### 3.1 复制节点

**方式一：快捷键**

1. 在画布中选中一个或多个节点（可框选或 `Ctrl+A` 全选）；
2. 按 `Ctrl+C`；
3. 界面右下角弹出提示："已复制 N 个节点"。

**方式二：右键菜单**

1. 在目标节点上点击右键；
2. 选择"复制节点"。

### 3.2 粘贴节点

**方式一：快捷键**

1. 按 `Ctrl+V`；
2. 新节点副本出现在原节点右下方，并自动处于选中状态。

**方式二：右键菜单**

1. 在画布空白处点击右键；
2. 选择"粘贴节点"（剪贴板为空时该选项不可用）。

### 3.3 多次粘贴

连续按 `Ctrl+V` 时，每次粘贴的副本会相对于原位置整体偏移递增：

- 第 1 次：偏移 30px
- 第 2 次：偏移 60px
- 第 3 次：偏移 90px
- ……

这样可以避免多次粘贴的节点堆叠在一起。

### 3.4 保留内部连接

当同时复制多个相互连接的节点时（例如 A → B → C），粘贴后会自动生成对应的 A' → B' → C' 连接。若复制范围外的节点与副本内节点有连接，则不会被复制。

## 四、快捷键速查

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 复制选中节点 |
| `Ctrl + V` | 粘贴节点 |
| `Ctrl + A` | 全选节点 |
| `Delete` | 删除选中节点或选中连线 |
| `Esc` | 取消所有选中 |

## 五、常见问题

### Q1：点击连线后没有黄色高亮？

- 确认当前未处于"建连"状态（即未点击某个节点的输出端口）。建连状态下会优先显示临时连线，且会清空连线选中态。
- 检查是否点击到了节点卡片而非连线本身。连线的命中区域为贝塞尔曲线周围约 8 像素范围。

### Q2：框选时总是选中节点而不是连线？

- 框选连线要求 rubber band 矩形覆盖连线的起点或终点。连线中段穿过框选区域不会被选中。
- 框选节点和框选连线可以同时发生：若框选区域同时包含节点和连线端点，则节点和连线均会被选中。

### Q3：粘贴后节点重叠？

- 连续多次粘贴会自动递增偏移。若手动把副本拖到原节点上方再次粘贴，可能出现视觉重叠，此时可拖动副本或按 `Ctrl+V` 继续生成新副本。

### Q4：复制节点后修改了原节点参数，粘贴出来的副本参数会跟着变吗？

- 不会。复制时会对节点做深拷贝，后续对原节点的修改不会影响剪贴板内容。

### Q5：为什么右键"复制节点"只复制了当前右键点击的节点？

- 右键菜单的"复制节点"以当前右键点击的节点为准。若要复制多个节点，请先框选多个节点，再使用 `Ctrl+C`。
