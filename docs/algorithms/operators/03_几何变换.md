## AffineTransImage（仿射变换）

### 核心含义
对图像进行二维仿射变换，支持平移、旋转、缩放、斜切等操作的任意组合，通过一个 2×3 仿射矩阵统一描述。仿射变换保持图像的平直性和平行性（直线变换后仍为直线，平行线变换后仍平行），是几何校正的基础工具。

与 ImageTransform 的区别：ImageTransform 提供预设的简单变换类型（resize/rotate/flip 等），参数易于使用；AffineTransImage 则通过矩阵直接描述任意仿射变换，灵活性更高但需要用户自行构造矩阵。

### 原理简述
仿射变换的数学形式：

```
| x' |   | a11  a12 |   | x |   | a13 |
|    | = |          | · |   | + |     |
| y' |   | a21  a22 |   | y |   | a23 |
```

等价于 `[x', y']ᵀ = A · [x, y]ᵀ + b`，其中 A 为 2×2 线性部分，b 为 2×1 平移部分，合并为 2×3 矩阵 `[A | b]`。

底层调用 `cv::warpAffine`，参数 `matrix` 为逗号分隔的 6 个值 `a11,a12,a13,a21,a22,a23`。默认值 `1,0,0,0,1,0` 为单位矩阵（不变换）。

### 适用场景
- 场景1：图像校正——通过标定得到的仿射矩阵校正倾斜的拍摄角度
- 场景2：数据增强——对样图做随机仿射变换扩充训练集
- 场景3：坐标对齐——将不同视角的图像对齐到统一坐标系

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| matrix | 变换矩阵 | String | "1,0,0,0,1,0" | - | - | 2x3 仿射矩阵（逗号分隔 6 个值：a11,a12,a13,a21,a22,a23） |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（变换结果，类型 Mat）——仿射变换后的图像

### 使用示例
典型配置——平移 (50, 30) 像素：

```json
{
  "type": "AffineTransImage",
  "params": {
    "matrix": "1,0,50,0,1,30"
  }
}
```

典型配置——绕原点旋转 30°（顺时针）：

```json
{
  "type": "AffineTransImage",
  "params": {
    "matrix": "0.866,0.5,0,-0.5,0.866,0"
  }
}
```

矩阵说明：旋转 30° 对应 `a11=cos30°, a12=sin30°, a21=-sin30°, a22=cos30°`，即 `0.866, 0.5, -0.5, 0.866`。

### 注意事项
- 矩阵必须为 6 个数值，逗号分隔，多余或不足会解析失败
- 变换后图像可能出现黑色填充区域（边界外像素），需通过后续裁剪或填充处理
- 默认插值方式为双线性插值，如需其他插值需在底层修改

### 关联算子
- **ImageTransform**：简单变换（resize/rotate/flip）的易用替代
- **PolarTransImage**：将环形区域展开为矩形，常配合本算子做圆环检测
- **ScaleImage**：仅做灰度缩放而非几何缩放

## PolarTransImage（极坐标变换）

### 核心含义
将图像以指定中心点做极坐标变换，把以该点为圆心的环形区域展开为矩形图像。在极坐标空间中，原来的圆弧变为水平直线、径向线变为垂直直线，便于对环形结构（如瓶口、轴承、轮胎）做展开检测。

该算子是圆形目标检测的关键预处理步骤，将难以在笛卡尔坐标下分析的环形特征转换为便于处理的线性特征。

### 原理简述
极坐标变换的映射关系：

```
ρ = √((x − cx)² + (y − cy)²)
θ = atan2(y − cy, x − cx)

x_polar = θ · R / (2π)    （周向坐标）
y_polar = ρ                 （径向坐标）
```

其中 `(cx, cy)` 为极坐标中心，由 `centerX / centerY` 指定。底层调用 `cv::warpPolar`，将原始图像中以 `(cx, cy)` 为中心的极坐标网格映射到矩形的行列坐标。

变换后的图像宽度对应角度（0~2π），高度对应半径。

### 适用场景
- 场景1：圆环展开——瓶口、轮胎、管道等环形目标的缺陷检测
- 场景2：字符识别——圆形排列的字符（如印章、表盘）展开为水平排列后 OCR
- 场景3：径向尺寸测量——展开后径向尺寸变为纵向像素，便于测量

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| centerX | 中心 X | Int | 320 | 0 ~ 8192 | px | 极坐标变换中心 X 坐标，步长 1 |
| centerY | 中心 Y | Int | 240 | 0 ~ 8192 | px | 极坐标变换中心 Y 坐标，步长 1 |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（变换结果，类型 Mat）——极坐标变换结果

### 使用示例
典型配置——以图像中心为极点展开：

```json
{
  "type": "PolarTransImage",
  "params": {
    "centerX": 320,
    "centerY": 240
  }
}
```

步骤说明：
1. 前置算子定位圆形目标中心坐标（可通过 Blob 分析获取重心）
2. 将中心坐标填入 `centerX / centerY`
3. 输出展开后的矩形图像，水平方向为周向（0~360°），垂直方向为径向
4. 后续连接 EdgeDetect 或 Blob 分析检测环形缺陷

### 注意事项
- 中心坐标必须落在图像范围内，否则展开结果会有大量黑边
- 默认参数 `centerX=320, centerY=240` 适配 640×480 分辨率，其他分辨率需调整
- 展开后的图像宽度由底层根据最大半径自动确定，无法直接控制

### 关联算子
- **AffineTransImage**：展开后可进一步做旋转或平移校正
- **EdgeDetect**：展开后的环形缺陷变为水平线段，便于边缘检测
- **ImageTransform**：展开图尺寸过大时可做 resize

## ImageTransform（图像变换）

### 核心含义
提供 5 种基础几何变换的统一入口：缩放（resize）、旋转（rotate）、翻转（flip）、仿射（affine）、透视（perspective）。通过 `transformType` 切换变换类型，其他参数根据类型自动生效。

与 AffineTransImage 的区别：ImageTransform 用语义化参数（角度、缩放比例、目标尺寸）描述变换，更适合快速应用；AffineTransImage 直接操作矩阵，适合需要精确控制变换的场景。

### 原理简述
各变换类型的底层实现：
- **resize**：调用 `cv::resize`，将图像缩放到 `targetWidth × targetHeight`，默认双线性插值
- **rotate**：调用 `cv::getRotationMatrix2D` + `cv::warpAffine`，绕图像中心旋转 `angle` 度（正值逆时针）
- **flip**：调用 `cv::flip`，`flipCode=0` 垂直翻转（上下），`1` 水平翻转（左右），`-1` 双向
- **affine**：通过 `scaleX/scaleY` 构造缩放矩阵，结合 `cv::warpAffine` 实现
- **perspective**：通过 `scaleX/scaleY` 构造 3×3 透视矩阵，调用 `cv::warpPerspective`

不同类型生效的参数：
- resize: `targetWidth, targetHeight`
- rotate: `angle`
- flip: `flipCode`
- affine / perspective: `scaleX, scaleY`

### 适用场景
- 场景1：分辨率标准化——将不同来源的图像统一到固定尺寸
- 场景2：方向校正——旋转图像到水平/垂直方向
- 场景3：数据增强——翻转、缩放扩充训练样本

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| transformType | 变换类型 | Enum | resize | resize / rotate / flip / affine / perspective | - | 5 种基本变换类型：缩放 / 旋转 / 翻转 / 仿射 / 透视 |
| angle | 旋转角度 | Double | 0 | -360 ~ 360 | ° | rotate 专用，步长 1 |
| scaleX | X 缩放 | Double | 1 | 0.01 ~ 10 | - | affine/perspective 专用，步长 0.1 |
| scaleY | Y 缩放 | Double | 1 | 0.01 ~ 10 | - | affine/perspective 专用，步长 0.1 |
| flipCode | 翻转码 | Int | 0 | -1 ~ 1 | - | flip 专用：0=垂直，1=水平，-1=双向，步长 1 |
| targetWidth | 目标宽度 | Int | 640 | 1 ~ 8192 | px | resize 专用，步长 1 |
| targetHeight | 目标高度 | Int | 480 | 1 ~ 8192 | px | resize 专用，步长 1 |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（变换结果，类型 Mat）——几何变换后的图像

### 使用示例
典型配置 1——resize 到 1920×1080：

```json
{
  "type": "ImageTransform",
  "params": {
    "transformType": "resize",
    "targetWidth": 1920,
    "targetHeight": 1080
  }
}
```

典型配置 2——水平翻转：

```json
{
  "type": "ImageTransform",
  "params": {
    "transformType": "flip",
    "flipCode": 1
  }
}
```

典型配置 3——旋转 90°：

```json
{
  "type": "ImageTransform",
  "params": {
    "transformType": "rotate",
    "angle": 90
  }
}
```

### 注意事项
- 非当前 `transformType` 对应的参数不会生效，但保留其值不影响执行
- 旋转和透视变换后图像尺寸不变，超出原图范围的像素会被裁剪，原图范围外的区域填充黑色
- `scaleX/scaleY` 仅在 affine/perspective 下生效，resize 使用 `targetWidth/targetHeight` 控制尺寸

### 关联算子
- **AffineTransImage**：需要精确矩阵控制的复杂仿射变换
- **ImageMerge**：变换后可与原图或其他图像合并对比
- **GrabImage**：采集图像尺寸不匹配时常用 resize 标准化

## ImageMerge（图像合并）

### 核心含义
将当前图像与上一帧缓存图合并为一张图像，支持水平拼接、垂直拼接、覆盖、Alpha 混合四种方式。用于多图对比展示、前后帧叠加、双视图分析等场景。

合并操作的第二操作数固定为"上一张缓存图"，因此在使用前需确保流程中已通过其他算子产生并缓存了第二张图像。

### 原理简述
四种合并类型的实现：
- **horizontal**（水平拼接）：调用 `cv::hconcat`，将两图按列拼接，要求行数（高度）相同
- **vertical**（垂直拼接）：调用 `cv::vconcat`，将两图按行拼接，要求列数（宽度）相同
- **overlay**（覆盖）：将当前图像直接覆盖在缓存图上方，左上角对齐，超出部分裁剪
- **alphaBlend**（Alpha 混合）：调用 `cv::addWeighted`，按 `output = alpha · src1 + (1−alpha) · src2` 加权融合

Alpha 混合中 `alpha` 为前景（当前图像）权重，`1−alpha` 为背景（缓存图）权重。

### 适用场景
- 场景1：结果对比——原始图与处理结果水平拼接便于对比
- 场景2：双视图展示——将掩膜与原图叠加显示检测结果
- 场景3：图像融合——多帧曝光融合、动态模糊效果

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| mergeType | 合并类型 | Enum | horizontal | horizontal / vertical / overlay / alphaBlend | - | 水平拼接 / 垂直拼接 / 覆盖 / Alpha 混合 |
| alpha | Alpha | Double | 0.5 | 0 ~ 1 | - | alphaBlend 专用（前景权重），步长 0.05 |

### 输入输出
- **输入**：当前图像 + 上一帧缓存图（作为第二操作数）
- **输出**：`image`（合并结果，类型 Mat）——图像合并结果

### 使用示例
典型配置 1——水平拼接原图与边缘检测结果：

```json
{
  "type": "ImageMerge",
  "params": {
    "mergeType": "horizontal",
    "alpha": 0.5
  }
}
```

步骤说明：
1. 用 ReadImage 加载原图并送入缓存
2. 后续 EdgeDetect 输出边缘图
3. 在边缘图之后放置 ImageMerge，`mergeType=horizontal`
4. 输出为原图与边缘图并排展示

典型配置 2——Alpha 混合（50% 透明叠加）：

```json
{
  "type": "ImageMerge",
  "params": {
    "mergeType": "alphaBlend",
    "alpha": 0.5
  }
}
```

### 注意事项
- 水平拼接要求两图高度一致，垂直拼接要求两图宽度一致，不一致会报错或自动裁剪
- `overlay` 模式以当前图像为前景，覆盖在缓存图左上角，尺寸不匹配时以当前图像为准
- `alpha` 仅在 `alphaBlend` 下生效，其他模式忽略此参数
- 第二操作数依赖缓存图机制，需确保流程顺序正确

### 关联算子
- **ImageArithmetic**：基于像素运算的图像融合（加/减/与/或）
- **EdgeDetect**：典型上游，检测结果与原图合并展示
- **ColorDetect**：颜色掩膜与原图叠加可视化
