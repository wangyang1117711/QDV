## SurfaceDefect（表面缺陷检测）

### 核心含义
表面缺陷检测算子基于模板差分与形态学处理检测表面缺陷区域，输出缺陷数量、是否有缺陷标志和缺陷列表。它解决的是"产品表面是否有划痕、凹坑、污渍等缺陷"的问题，是外观检测的核心算子。通过将待测图与无缺陷模板对齐差分，再经形态学优化提取缺陷区域。

### 原理简述
检测流程：
1. **配准对齐**：将待测图像与模板图像做特征配准，消除位置偏差
2. **差分计算**：`diff = |image - template|`，得到差分图
3. **高斯模糊**：用 blurSize 核大小做高斯模糊，抑制噪声
4. **阈值分割**：根据 sensitivity 灵敏度自适应阈值，分割缺陷候选区
5. **形态学处理**：用 morphKernelSize 核做开/闭运算，去除小噪点、连接断裂区域
6. **面积过滤**：保留 minDefectArea ≤ 面积 ≤ maxDefectArea 的连通域作为缺陷

sensitivity 越高，检测阈值越低，能发现更微小的缺陷但误检率上升。

### 适用场景
- 场景1：金属表面划痕、凹坑检测
- 场景2：塑料件表面污渍、色差检测
- 场景3：印刷品缺字、漏印检测

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| templatePath | 模板路径 | String | "" | - | - | 无缺陷模板图像路径 |
| sensitivity | 灵敏度 | Double | 3 | - | - | 缺陷检测灵敏度 |
| minDefectArea | 最小缺陷面积 | Double | 50 | - | - | 最小缺陷区域面积 |
| maxDefectArea | 最大缺陷面积 | Double | 10000 | - | - | 最大缺陷区域面积 |
| morphKernelSize | 形态学核大小 | Int | 3 | - | - | 形态学操作核大小 |
| blurSize | 模糊核大小 | Int | 3 | - | - | 高斯模糊核大小 |

### 输入输出
- **输入**：待测图像 + 无缺陷模板图像（templatePath 指定）
- **输出**：
  - `defectCount`（int）：检测到的缺陷数量
  - `hasDefect`（bool）：是否存在缺陷
  - `defects`（Defect[]）：缺陷区域列表

### 使用示例
金属表面划痕检测配置：
```json
{
  "templatePath": "D:/templates/metal_ok.png",
  "sensitivity": 4,
  "minDefectArea": 30,
  "maxDefectArea": 5000,
  "morphKernelSize": 3,
  "blurSize": 3
}
```
步骤说明：加载无缺陷模板 → 待测图与模板配准差分 → 高斯模糊去噪 → 灵敏度 4 阈值分割 → 形态学开运算去噪点 → 过滤面积 30-5000 的缺陷 → 输出缺陷列表。

### 注意事项
- 模板图像必须是无缺陷的标准件，且光照条件与待测图一致
- sensitivity 过高会导致噪声误判为缺陷，需根据实际场景调参
- morphKernelSize 和 blurSize 应为奇数（高斯模糊要求）

### 关联算子
- [SegmentDl]：深度学习分割可作为传统差分的替代方案，精度更高
- [ContourCompare]：缺陷区域轮廓比对评估缺陷形状偏差
- [BranchControl]：根据 hasDefect 分支决定合格/不合格流向

## ContourCompare（轮廓比对）

### 核心含义
轮廓比对算子将目标轮廓与模板轮廓进行比对，输出偏差值、匹配分数和是否匹配标志。它解决的是"工件轮廓与标准轮廓有多大偏差"的问题，适用于成型件尺寸检验、冲压件轮廓度评估等场景。支持 I1/I2/I3 三种比对方法。

### 原理简述
轮廓比对基于 Hu 矩或轮廓距离度量：
1. **轮廓提取**：从图像中提取目标轮廓（findContours）
2. **模板加载**：从 templatePath 加载标准轮廓
3. **配准对齐**：将目标轮廓与模板轮廓对齐（平移+缩放+旋转）
4. **偏差计算**：逐点计算轮廓间距离，maxDeviation 为允许的最大偏差
5. **匹配评分**：根据偏差分布计算匹配分数 score（0-1）
6. **方法选择**：I1/I2/I3 对应不同的 Hu 矩或距离度量组合

score ≥ minScore 时 isMatch 为 true，判定为轮廓合格。

### 适用场景
- 场景1：冲压件轮廓度检验，评估与设计图纸的偏差
- 场景2：注塑件外形检测，发现缩水、变形
- 场景3：切割件尺寸验证，确保切割轨迹精度

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| templatePath | 模板路径 | String | "" | - | - | 标准轮廓模板文件路径 |
| maxDeviation | 最大偏差 | Double | 5 | - | px | 允许的最大轮廓偏差 |
| matchMethod | 匹配方法 | Enum | I1 | I1/I2/I3 | - | 轮廓比对方法 |
| minScore | 最小分数 | Double | 0.8 | - | - | 最小匹配分数阈值 |

### 输入输出
- **输入**：待测图像（需能提取轮廓）+ 标准轮廓模板
- **输出**：
  - `deviation`（float）：轮廓偏差值
  - `score`（float）：轮廓匹配分数
  - `isMatch`（bool）：是否达到匹配标准

### 使用示例
冲压件轮廓检验配置：
```json
{
  "templatePath": "D:/templates/stamp_contour.yml",
  "maxDeviation": 3,
  "matchMethod": "I1",
  "minScore": 0.85
}
```
步骤说明：提取待测件轮廓 → 加载标准轮廓模板 → I1 方法配准比对 → 计算偏差（px）与匹配分数 → 分数 ≥ 0.85 判定合格。

### 注意事项
- maxDeviation 单位为像素，需结合实际分辨率换算为物理量
- I1/I2/I3 三种方法对噪声敏感度不同，建议先用样本对比选择最优方法
- 待测图像需做好预处理（二值化），轮廓提取质量直接影响比对精度

### 关联算子
- [SurfaceDefect]：轮廓比对用于外形检验，表面缺陷检测用于外观检验，二者互补
- [Caliper]：轮廓局部偏差可用卡尺做精细尺寸测量
- [UnitConvert]：将偏差（px）换算为物理单位（mm）输出
