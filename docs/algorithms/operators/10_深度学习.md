## AiClassify（AI 分类）

### 核心含义
AI 分类算子使用训练好的深度学习模型对输入图像进行整图分类，输出类别 ID、类别名称和置信度。它解决的是"这张图是什么"的问题，适用于 OK/NG 判定、物料识别、场景识别等场景。算子支持 PyTorch、ONNX、TensorRT 三种推理后端，并支持 Top-K 输出和多目标批量分类。

### 原理简述
分类模型通常基于 ResNet/MobileNet/ViT 等 backbone，输入固定尺寸的图像（默认 224×224），经过卷积特征提取与全连接层后输出一个长度为类别数的 logits 向量，经 Softmax 归一化后得到各类别概率。算子取概率最大的类别作为预测结果，并按置信度阈值过滤低分预测。Top-K 参数控制返回前 K 个候选类别，便于多候选场景下的二次决策。

### 适用场景
- 场景1：产品外观 OK/NG 二分类，替代人工目检
- 场景2：物料种类识别，区分不同型号工件
- 场景3：场景/工序识别，根据图像内容自动切换后续流程

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| modelPath | 模型路径 | String | "" | - | - | 推荐 .pt / .onnx 格式 |
| confidenceThreshold | 置信度阈值 | Double | 0.5 | [0, 1] | - | 分数 ≥ 阈值 视为 OK |
| topK | Top-K | Int | 3 | [1, 100] | - | 返回前 K 个分类 |
| inputWidth | 输入宽 | Int | 224 | [32, 4096] | px | 模型输入尺寸 |
| inputHeight | 输入高 | Int | 224 | [32, 4096] | px | 模型输入尺寸 |
| categoryLabels | 类别标签 | Mat | "" | - | - | 每行一个类别名（顺序对应模型输出索引） |

### 输入输出
- **输入**：单张彩色或灰度图像（建议与模型训练时的颜色空间一致）
- **输出**：
  - `classId`（int）：分类标签的数值ID
  - `className`（string）：分类类别名称（单目标为字符串，多目标为数组）
  - `confidence`（double）：分类置信度（单目标为数值，多目标为数组）
  - `classArray`（string[]）：多目标场景下按检测顺序输出的类别名数组（仅多目标）
  - `confidenceArray`（double[]）：多目标场景下按检测顺序输出的置信度数组（仅多目标）

### 使用示例
典型 OK/NG 分类配置：
```json
{
  "modelPath": "D:/models/ok_ng_resnet18.onnx",
  "confidenceThreshold": 0.85,
  "topK": 1,
  "inputWidth": 224,
  "inputHeight": 224,
  "categoryLabels": "OK\nNG"
}
```
步骤说明：加载 ONNX 模型 → 图像 resize 到 224×224 → 推理得到概率 → 取 Top-1 → 置信度 ≥ 0.85 视为 OK，否则视为 NG。

### 注意事项
- 模型输入尺寸必须与训练时一致，否则精度下降；常见值为 224/256/384
- categoryLabels 的行顺序必须与模型输出索引严格对应，否则类别名错位
- 多目标场景下需配合上游检测算子提供 ROI，否则按整图单目标处理

### 关联算子
- [Normalization]：在分类前对图像做 ImageNet 标准化预处理
- [YoloDetect]：先检测再对每个 ROI 调用 AiClassify 实现多目标分类
- [BranchControl]：根据 classId 或 confidence 分支决定后续流程

## YoloDetect（YOLO 检测）

### 核心含义
YOLO 检测算子使用 YOLOv5/v8 系列目标检测模型在图像中定位多个目标，输出检测框数组（含类别 ID、置信度、bbox）和检测数量。它解决的是"图里有什么、在哪里"的问题，是工业检测中最常用的目标检测算子。支持多类别检测、NMS 去重和边界框可视化。

### 原理简述
YOLO 将输入图像划分为 S×S 网格，每个网格预测 B 个边界框及其置信度和类别概率。模型输出经解码后得到候选框集合，再通过非极大值抑制（NMS）去除重叠框：对按置信度排序的框，若与当前框的 IoU 超过 iouThreshold 则抑制。最终保留的框即为检测结果。置信度阈值过滤掉低分检测，平衡召回率与精确率。

### 适用场景
- 场景1：流水线多目标定位，如零件计数、缺料检测
- 场景2：缺陷区域初定位，配合后续精细分析
- 场景3：安全检测，如人员/设备是否在位

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| modelPath | 模型路径 | String | "" | - | - | 推荐 .onnx 格式 YOLO 模型 |
| confidenceThreshold | 置信度阈值 | Double | 0.25 | [0, 1] | - | 分数 ≥ 阈值 视为有效检测 |
| iouThreshold | NMS IoU阈值 | Double | 0.45 | [0, 1] | - | 非极大值抑制 IoU 阈值 |
| inputWidth | 输入宽 | Int | 640 | [32, 4096] | px | YOLO 模型输入尺寸 |
| inputHeight | 输入高 | Int | 640 | [32, 4096] | px | YOLO 模型输入尺寸 |
| categoryLabels | 类别标签 | Mat | "" | - | - | 每行一个类别名（顺序对应模型输出索引） |

### 输入输出
- **输入**：单张彩色或灰度图像（YOLO 通常要求 BGR/RGB 彩色图）
- **输出**：
  - `detections`（Detection[]）：检测框数组（含 class_id/confidence/bbox）
  - `numDetections`（int）：检测到的目标数量

### 使用示例
多类别零件检测配置：
```json
{
  "modelPath": "D:/models/parts_yolov8n.onnx",
  "confidenceThreshold": 0.5,
  "iouThreshold": 0.45,
  "inputWidth": 640,
  "inputHeight": 640,
  "categoryLabels": "screw\nnut\nwasher\nbolt"
}
```
步骤说明：模型加载 → 图像 letterbox 到 640×640 → 推理 → NMS 去重 → 坐标还原到原图 → 输出检测框列表。

### 注意事项
- inputWidth/inputHeight 必须是 32 的倍数（YOLO 下采样要求），否则推理报错
- iouThreshold 过低会误删邻近目标，过高会导致重复框；密集场景建议 0.4-0.5
- 类别标签顺序必须与模型训练时 names.yaml 顺序一致

### 关联算子
- [AiClassify]：对 YOLO 检测到的每个 ROI 做细粒度分类
- [SegmentDl]：检测后对 ROI 做实例分割获取精确掩膜
- [BranchControl]：根据 numDetections 是否为 0 分支控制后续流程

## SegmentDl（深度学习分割）

### 核心含义
深度学习分割算子使用 UNet/MaskRCNN 等模型对图像进行语义分割或实例分割，输出与输入同尺寸的掩膜（mask）。它解决的是"每个像素属于哪个类别"的问题，适用于缺陷区域精确分割、前景背景分离、器官/区域划分等场景。

### 原理简述
语义分割模型采用编码器-解码器结构（如 UNet）：编码器通过下采样提取多尺度特征，解码器通过上采样恢复分辨率，跳跃连接融合高低层信息。输出为 H×W×C 的概率图，C 为类别数。对每个像素取 argmax 得到类别标签，再经 confidenceThreshold 阈值过滤低置信度像素，生成二值或多值掩膜。实例分割（如 MaskRCNN）则在检测框基础上增加掩膜分支。

### 适用场景
- 场景1：缺陷区域精确分割，计算缺陷面积与形状
- 场景2：前景提取，分离工件与背景
- 场景3：医学/材料图像的区域划分与统计

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| modelPath | 模型路径 | String | "" | - | - | 推荐 .pt / .onnx 语义分割模型 |
| confidenceThreshold | 置信度阈值 | Double | 0.5 | [0, 1] | - | 像素级分类置信度阈值 |
| inputWidth | 输入宽 | Int | 512 | [32, 4096] | px | 模型输入尺寸宽度 |
| inputHeight | 输入高 | Int | 512 | [32, 4096] | px | 模型输入尺寸高度 |

### 输入输出
- **输入**：单张彩色或灰度图像
- **输出**：
  - `mask`（Mat）：语义分割结果掩膜

### 使用示例
缺陷分割配置：
```json
{
  "modelPath": "D:/models/defect_unet.onnx",
  "confidenceThreshold": 0.6,
  "inputWidth": 512,
  "inputHeight": 512
}
```
步骤说明：加载模型 → 图像 resize 到 512×512 → 推理得到概率图 → 阈值过滤 → 输出二值掩膜，白色区域为缺陷。

### 注意事项
- 分割模型对输入分辨率敏感，建议使用训练时的尺寸
- 输出掩膜需与原图尺寸对齐，注意 resize 后的坐标映射
- 像素级阈值过高会导致缺陷区域缩小，过低会引入噪点

### 关联算子
- [YoloDetect]：先检测定位 ROI，再对 ROI 做分割提升精度
- [SurfaceDefect]：分割掩膜可作为缺陷区域输入面积统计
- [Normalization]：分割前对图像做标准化预处理提升模型稳定性

## DetectObjectsDl（深度学习检测）

### 核心含义
深度学习检测算子使用 YOLO/SSD/FasterRCNN 等模型进行通用目标检测，输出目标检测结果列表。与 YoloDetect 相比，本算子支持更广泛的检测模型格式（.pt/.onnx/.engine），适用于需要灵活切换检测框架的场景。

### 原理简述
通用目标检测框架分为单阶段（YOLO/SSD）和两阶段（FasterRCNN）。单阶段直接在特征图上回归边界框与类别；两阶段先由 RPN 生成候选框，再对候选框分类与回归。无论哪种框架，输出均经过 NMS 去重：按置信度排序，IoU 超过 nmsThreshold 的框被抑制。最终保留置信度 ≥ confidenceThreshold 的检测框。

### 适用场景
- 场景1：使用非 YOLO 框架（如 SSD/FasterRCNN）的目标检测
- 场景2：需要 TensorRT 加速（.engine）的高性能检测
- 场景3：多模型对比测试，灵活切换检测后端

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| modelPath | 模型路径 | String | "" | - | - | 推荐 .pt / .onnx / .engine 目标检测模型 |
| confidenceThreshold | 置信度阈值 | Double | 0.5 | [0, 1] | - | 检测框置信度阈值 |
| nmsThreshold | NMS IoU 阈值 | Double | 0.45 | [0, 1] | - | 非极大值抑制 IoU 阈值 |
| inputWidth | 输入宽 | Int | 640 | [32, 4096] | px | 模型输入尺寸宽度 |
| inputHeight | 输入高 | Int | 640 | [32, 4096] | px | 模型输入尺寸高度 |

### 输入输出
- **输入**：单张彩色或灰度图像
- **输出**：
  - `detections`（Detection[]）：目标检测结果列表

### 使用示例
使用 TensorRT 引擎加速检测：
```json
{
  "modelPath": "D:/models/detect_v8.engine",
  "confidenceThreshold": 0.5,
  "nmsThreshold": 0.45,
  "inputWidth": 640,
  "inputHeight": 640
}
```
步骤说明：加载 .engine 模型 → 图像预处理 → GPU 推理 → NMS → 输出检测框列表。TensorRT 引擎相比 ONNX 有 3-5 倍加速。

### 注意事项
- .engine 文件与 GPU 架构绑定，换卡需重新转换
- 不同检测框架的输出解码逻辑不同，需确保模型已适配算子的输入输出协议
- NMS 阈值需根据目标密度调整，密集小目标场景建议降低到 0.3-0.4

### 关联算子
- [YoloDetect]：专用于 YOLO 系列，若使用 YOLO 模型推荐改用 YoloDetect
- [SegmentDl]：检测后对 ROI 做实例分割获取掩膜
- [BranchControl]：根据检测结果数量分支控制

## Normalization（均一化）

### 核心含义
均一化算子为深度学习预处理提供多种数值标准化模式，将图像像素值映射到模型期望的分布区间。它解决的是"如何让输入数据分布与训练时一致"的问题，直接影响模型推理精度。支持 MinMax、ZScore、LayerNorm、InstanceNorm、BatchNorm、ImageNet 六种模式。

### 原理简述
各模式公式如下：
- **MinMax**：`x' = (x - min) / (max - min)`，可映射到 [0,1] 或 [-1,1]
- **ZScore**：`x' = (x - μ) / σ`，均值为 0 方差为 1
- **LayerNorm**：沿通道维度计算 μ 和 σ，对每个像素位置归一化
- **InstanceNorm**：对单张图的每个通道独立计算 μ 和 σ
- **BatchNorm**：使用训练阶段的滑动均值/方差
- **ImageNet**：使用固定均值 [0.485,0.456,0.406] 和标准差 [0.229,0.224,0.225]，适用于 ImageNet 预训练模型

epsilon 为防止除零的小常数。

### 适用场景
- 场景1：使用 ImageNet 预训练模型（ResNet/MobileNet）时的标准化预处理
- 场景2：自定义模型需要特定输入区间（如 GAN 需要 [-1,1]）
- 场景3：不同光照条件下通过 InstanceNorm 提升模型鲁棒性

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| mode | 均一化模式 | Enum | minMax | minMax/zScore/layerNorm/instanceNorm/batchNorm/imageNet | - | 选择标准化模式 |
| targetRange | 目标区间 | Enum | 0_1 | 0_1/minus1_1 | - | 仅 minMax 模式有效：0_1 映射到 [0,1]；minus1_1 映射到 [-1,1] |
| perChannel | 逐通道计算 | Bool | true | - | - | 是否对每个通道独立计算统计量（minMax/layerNorm 生效） |
| mean | 自定义均值 | Mat | "" | - | - | 逗号分隔的均值列表，如 0.485,0.456,0.406。留空时 zScore 自动计算、imageNet 使用 ImageNet 默认值 |
| std | 自定义标准差 | Mat | "" | - | - | 逗号分隔的标准差列表，如 0.229,0.224,0.225。留空时 zScore 自动计算、imageNet 使用 ImageNet 默认值 |
| epsilon | Epsilon | Double | 1e-05 | [1e-12, 1.0] | - | 防止除零的小常数，必须 > 0 |

### 输入输出
- **输入**：单张图像（彩色或灰度，8 位或浮点）
- **输出**：
  - `normalizedImage`（Mat）：标准化后的 float32 图像（overlayImage 为映射到 [0,255] 的显示图）

### 使用示例
ImageNet 预训练模型的标准预处理：
```json
{
  "mode": "imageNet",
  "targetRange": "0_1",
  "perChannel": true,
  "mean": "",
  "std": "",
  "epsilon": 1e-05
}
```
步骤说明：选择 imageNet 模式 → 自动使用 [0.485,0.456,0.406] 均值和 [0.229,0.224,0.225] 标准差 → 像素值先除以 255 归一化到 [0,1] → 再减均值除标准差 → 输出 float32 图像供模型推理。

### 注意事项
- targetRange 仅在 minMax 模式下生效，其他模式忽略此参数
- mean/std 留空时，zScore 自动从当前图像计算统计量，imageNet 使用默认值
- epsilon 过大会导致归一化失真，建议保持默认 1e-5

### 关联算子
- [AiClassify]：分类前使用 Normalization 做标准化预处理
- [YoloDetect]：检测前可根据模型需求做归一化
- [SegmentDl]：分割前做标准化提升模型稳定性
