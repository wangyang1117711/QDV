## GeometryMeasure（几何测量）

### 核心含义
几何测量算子基于图像中最大轮廓的物理量进行测量，支持距离、面积、周长、角度、圆半径五种测量类型。该算子将像素测量结果通过 `pixelScale` 转换为物理单位（如毫米），并支持 NG（不合格）判定。

该算子是工业检测中尺寸测量的核心工具，常用于工件尺寸检验、装配精度检测等场景。

### 原理简述
算子的测量流程：

1. **轮廓提取**：对输入图像进行二值化（内部 OTSU 或阈值），提取最大面积的轮廓。
2. **几何量计算**：根据 `measureType` 计算对应的几何量：
   - `distance`：基于轮廓外接矩形计算最大尺寸（长边或对角线）。
   - `area`：轮廓包围的面积（`cv::contourArea`）。
   - `perimeter`：轮廓周长（`cv::arcLength`）。
   - `angle`：基于轮廓拟合直线或外接矩形计算倾斜角度。
   - `circleRadius`：对轮廓进行最小外接圆拟合（`cv::minEnclosingCircle`），返回半径。
3. **单位转换**：将像素测量值乘以 `pixelScale` 转换为物理单位（如 mm）。
4. **NG 判定**：若测量值小于 `minThreshold` 或大于 `maxThreshold`，判定为 NG。

### 适用场景
- 场景1：工件尺寸测量，如长度、宽度、直径检验。
- 场景2：装配间隙检测，测量两部件之间的距离。
- 场景3：圆形零件半径测量，如孔径、轴径检测。
- 场景4：角度测量，如零件倾斜角度检测。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| measureType | 测量类型 | Enum | distance | distance / area / perimeter / angle / circleRadius | - | 基于最大轮廓的物理量测量 |
| minThreshold | 最小阈值 | Double | 0 | 0 ~ 1000000 | - | 小于此值视为 NG，步长 1 |
| maxThreshold | 最大阈值 | Double | 1000 | 0 ~ 1000000 | - | 大于此值视为 NG，步长 1 |
| pixelScale | 像素→物理比例 | Double | 1 | 1e-06 ~ 1000000 | mm/px | 每像素对应的物理量（如 0.05 mm/px），步长 0.001 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。图像中应包含清晰的待测目标轮廓。
- **输出**：
  - `measures`（Measure[]）：测量结果，类型为 Measure 数组，描述为"几何测量结果"。

### 使用示例
测量工件长度并判定合格性：
```json
{
  "type": "GeometryMeasure",
  "params": {
    "measureType": "distance",
    "minThreshold": 9.5,
    "maxThreshold": 10.5,
    "pixelScale": 0.05
  }
}
```
步骤说明：测量类型为距离，`pixelScale=0.05` 表示每像素对应 0.05mm，合格范围 9.5~10.5mm，超出范围判定为 NG。

测量圆形零件半径：
```json
{
  "type": "GeometryMeasure",
  "params": {
    "measureType": "circleRadius",
    "minThreshold": 4.8,
    "maxThreshold": 5.2,
    "pixelScale": 0.02
  }
}
```
步骤说明：测量类型为圆半径，`pixelScale=0.02` mm/px，合格半径范围 4.8~5.2mm。

### 注意事项
- `pixelScale` 需通过相机标定获取准确值，错误的标定会导致测量结果偏差。
- 算子基于最大轮廓进行测量，若图像中有多个目标，需先用 ROI 裁剪或配合 [SelectShape](06_Blob与轮廓分析.md#selectshape形状选择) 筛选。
- `measureType` 为 `angle` 时，角度基准取决于轮廓形状，复杂轮廓可能不准确。
- `minThreshold` 和 `maxThreshold` 的单位与 `pixelScale` 一致（如 mm），设置时需注意。
- 测量精度依赖于轮廓提取质量，建议先用 [EdgesSubPix](07_特征提取与识别.md#edgessubpix亚像素边缘) 提升边缘精度。

### 关联算子
- [ContourAnalyze](06_Blob与轮廓分析.md#contouranalyze轮廓分析)：提取轮廓后配合几何测量。
- [LineCircleDetect](07_特征提取与识别.md#linecircledetect线圆检测)：检测直线/圆后可直接测量。
- [DistancePp](#distancepp点到点距离)：点到点距离的专用测量工具。
- [AngleLl](#anglell线到线角度)：线到线角度的专用测量工具。
- [AreaCenter](06_Blob与轮廓分析.md#areacenter面积中心点)：面积测量与重心计算。
- [Threshold](05_图像分割.md#threshold阈值分割)：二值化预处理生成轮廓。

## DistancePp（点到点距离）

### 核心含义
点到点距离算子计算两个指定点之间的欧氏距离，是最基础的几何测量工具。用户通过坐标指定两个点，算子返回两点间的直线距离（像素单位）。

该算子常用于测量目标上两个特征点之间的间距，如孔间距、边距等。

### 原理简述
算子计算点 `(x1, y1)` 和点 `(x2, y2)` 之间的欧氏距离：

```
distance = sqrt((x2 - x1)² + (y2 - y1)²)
```

结果以像素为单位输出。若需转换为物理单位（如 mm），可将结果乘以标定得到的 `pixelScale`。

### 适用场景
- 场景1：两孔间距测量，如 PCB 板上焊盘间距。
- 场景2：目标尺寸测量，如工件两端点间距。
- 场景3：位置偏差检测，如目标实际位置与理论位置的偏差。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| x1 | 点1 X | Double | 100 | 0 ~ 8192 | px | 第一个点的 X 坐标，步长 1 |
| y1 | 点1 Y | Double | 100 | 0 ~ 8192 | px | 第一个点的 Y 坐标，步长 1 |
| x2 | 点2 X | Double | 200 | 0 ~ 8192 | px | 第二个点的 X 坐标，步长 1 |
| y2 | 点2 Y | Double | 200 | 0 ~ 8192 | px | 第二个点的 Y 坐标，步长 1 |

### 输入输出
- **输入**：无需图像输入（基于坐标计算），但通常与图像处理流程配合使用，坐标可来自 [PointsHarris](07_特征提取与识别.md#pointsharrisharris-角点) 或 [AreaCenter](06_Blob与轮廓分析.md#areacenter面积中心点) 等算子的输出。
- **输出**：
  - `distance`（float）：点对距离，类型为 float，描述为"两点间距离"。

### 使用示例
计算两点间距离：
```json
{
  "type": "DistancePp",
  "params": {
    "x1": 100,
    "y1": 100,
    "x2": 300,
    "y2": 400
  }
}
```
步骤说明：计算点 (100,100) 到点 (300,400) 的欧氏距离，结果为 `sqrt(200² + 300²) = sqrt(130000) ≈ 360.56` 像素。

配合特征点检测使用：
```json
{
  "type": "DistancePp",
  "params": {
    "x1": "{{harris_points[0].x}}",
    "y1": "{{harris_points[0].y}}",
    "x2": "{{harris_points[1].x}}",
    "y2": "{{harris_points[1].y}}"
  }
}
```
步骤说明：使用前序 [PointsHarris](07_特征提取与识别.md#pointsharrisharris-角点) 算子输出的角点坐标作为输入，计算两个角点之间的距离。

### 注意事项
- 坐标值应在图像有效范围内（0~8192），超出范围会产生异常结果。
- 输出距离单位为像素，需乘以 `pixelScale` 转换为物理单位。
- 两点重合时距离为 0，不会报错。
- 坐标可通过变量引用前序算子的输出（如角点、重心坐标）。

### 关联算子
- [PointsHarris](07_特征提取与识别.md#pointsharrisharris-角点)：提供角点坐标作为距离测量的输入。
- [AreaCenter](06_Blob与轮廓分析.md#areacenter面积中心点)：提供重心坐标作为距离测量的输入。
- [AngleLl](#anglell线到线角度)：基于线段端点计算角度，与距离测量配合使用。
- [GeometryMeasure](#geometrymeasure几何测量)：更通用的几何测量工具，支持面积、周长等。
- [BlobDetect](06_Blob与轮廓分析.md#blobdetect斑块检测)：斑块中心可作为距离测量的端点。

## AngleLl（线到线角度）

### 核心含义
线到线角度算子计算两条直线之间的夹角，两条直线分别由各自的起点和终点定义。该算子输出两线段的夹角（弧度），常用于角度检测和姿态测量。

角度测量是工业检测中的常见需求，如零件倾斜角度、两条边缘的夹角等。

### 原理简述
算子基于两条直线的方向向量计算夹角。对于线段1（`(l1x1, l1y1)` → `(l1x2, l1y2)`）和线段2（`(l2x1, l2y1)` → `(l2x2, l2y2)`）：

1. 计算方向向量：`v1 = (l1x2 - l1x1, l1y2 - l1y1)`，`v2 = (l2x2 - l2x1, l2y2 - l1y1)`。
2. 计算夹角：`θ = atan2(|v1 × v2|, v1 · v2)`，其中 `×` 为叉积，`·` 为点积。
3. 输出弧度值，范围 [0, π]。

也可使用 `cos(θ) = (v1·v2) / (|v1|·|v2|)` 计算，但 `atan2` 方法在角度接近 0 或 π 时数值更稳定。

### 适用场景
- 场景1：零件倾斜角度检测，如安装角度偏差。
- 场景2：两条边缘夹角测量，如 V 型槽角度。
- 场景3：姿态校正，计算目标实际角度与理论角度的偏差。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| l1x1 | 线1 起点X | Double | 100 | 0 ~ 8192 | px | 第一条线起点 X，步长 1 |
| l1y1 | 线1 起点Y | Double | 100 | 0 ~ 8192 | px | 第一条线起点 Y，步长 1 |
| l1x2 | 线1 终点X | Double | 200 | 0 ~ 8192 | px | 第一条线终点 X，步长 1 |
| l1y2 | 线1 终点Y | Double | 100 | 0 ~ 8192 | px | 第一条线终点 Y，步长 1 |
| l2x1 | 线2 起点X | Double | 100 | 0 ~ 8192 | px | 第二条线起点 X，步长 1 |
| l2y1 | 线2 起点Y | Double | 200 | 0 ~ 8192 | px | 第二条线起点 Y，步长 1 |
| l2x2 | 线2 终点X | Double | 200 | 0 ~ 8192 | px | 第二条线终点 X，步长 1 |
| l2y2 | 线2 终点Y | Double | 200 | 0 ~ 8192 | px | 第二条线终点 Y，步长 1 |

### 输入输出
- **输入**：无需图像输入（基于坐标计算），但通常与图像处理流程配合使用，线段端点可来自 [LineCircleDetect](07_特征提取与识别.md#linecircledetect线圆检测) 算子的输出。
- **输出**：
  - `angle`（float）：线段夹角，类型为 float，描述为"两线段夹角（弧度）"。

### 使用示例
计算两条垂直线段的夹角：
```json
{
  "type": "AngleLl",
  "params": {
    "l1x1": 100,
    "l1y1": 100,
    "l1x2": 200,
    "l1y2": 100,
    "l2x1": 100,
    "l2y1": 100,
    "l2x2": 100,
    "l2y2": 200
  }
}
```
步骤说明：线段1为水平线（(100,100)→(200,100)），线段2为垂直线（(100,100)→(100,200)），两线垂直，夹角应为 π/2（约 1.5708 弧度 = 90°）。

配合直线检测使用：
```json
{
  "type": "AngleLl",
  "params": {
    "l1x1": "{{lines[0].x1}}",
    "l1y1": "{{lines[0].y1}}",
    "l1x2": "{{lines[0].x2}}",
    "l1y2": "{{lines[0].y2}}",
    "l2x1": "{{lines[1].x1}}",
    "l2y1": "{{lines[1].y1}}",
    "l2x2": "{{lines[1].x2}}",
    "l2y2": "{{lines[1].y2}}"
  }
}
```
步骤说明：使用前序 [LineCircleDetect](07_特征提取与识别.md#linecircledetect线圆检测) 算子输出的直线端点作为输入，计算两条检测到的直线之间的夹角。

### 注意事项
- 输出角度单位为弧度，需乘以 `180/π`（约 57.2958）转换为度数。
- 当线段长度为 0（起点等于终点）时，方向向量无法计算，会产生异常。
- 夹角范围为 [0, π]（0°~180°），不区分方向（无向角）。
- 线段端点坐标可通过变量引用前序算子（如 [LineCircleDetect](07_特征提取与识别.md#linecircledetect线圆检测)）的输出。
- 若需计算有向角度（区分顺时针/逆时针），需基于叉积符号额外处理。

### 关联算子
