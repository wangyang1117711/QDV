## DynThreshold（动态阈值）

### 核心含义
动态阈值分割算子根据图像局部均值自适应地计算阈值，将像素与局部均值进行比较从而分割出前景区域。与全局阈值不同，动态阈值能够适应图像中光照不均匀、背景渐变等场景，避免了单一阈值无法兼顾整幅图像的问题。

该算子常用于在光照变化的工业图像中提取目标前景，例如在反光表面或背光场景中分离目标与背景。

### 原理简述
算子首先对输入图像进行局部均值滤波（类似 HALCON 的 `dyn_threshold`），得到平滑后的参考图像 `mean`，然后将原图像 `src` 与 `mean` 按下式比较：

- `dark` 模式：`src < mean - offset`
- `light` 模式：`src > mean + offset`
- `equal` 模式：`|src - mean| <= offset`
- `not_equal` 模式：`|src - mean| > offset`

其中 `offset` 为阈值偏移量，用于控制分割的严格程度。局部均值的核大小由内部默认配置，`offset` 越小，对微小灰度差异越敏感。

### 适用场景
- 场景1：工业检测中光照不均匀的工件前景提取（如金属反光表面）。
- 场景2：背景存在渐变阴影，全局阈值无法有效分割的场景。
- 场景3：需要提取比局部背景更暗或更亮的目标区域。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| offset | 偏移量 | Int | 5 | -255 ~ 255 | - | 阈值偏移（像素值），步长 1 |
| mode | 模式 | Enum | dark | dark / light / equal / not_equal | - | 提取暗区域或亮区域 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。建议输入经过预处理（去噪/平滑）的图像以提升稳定性。
- **输出**：
  - `region`（Region）：动态阈值分割区域，类型为 Region，描述为"动态阈值分割区域"。

### 使用示例
提取金属表面比局部背景更暗的缺陷区域：
```json
{
  "type": "DynThreshold",
  "params": {
    "offset": 8,
    "mode": "dark"
  }
}
```
步骤说明：先将原图转为灰度图，调用 DynThreshold，设置 `offset=8` 增强对暗缺陷的敏感性，`mode=dark` 表示提取比局部均值低 8 以上的像素作为前景。

### 注意事项
- `offset` 取负值时语义会反转，例如 `mode=dark` 且 `offset=-5` 时实际提取的是 `src < mean + 5` 的区域，使用时需注意符号。
- 输入应为单通道图像，若传入彩色图像需先转换为灰度图。
- 局部均值核大小由内部配置决定，若图像尺寸过小可能导致参考图像边界效应明显。

### 关联算子
- [Threshold](#threshold阈值分割)：当光照均匀时可改用全局阈值分割，计算更快。
- [Connection](06_Blob与轮廓分析.md#connection连通域分析)：动态阈值结果通常需配合连通域分析提取独立目标。
- [SelectShape](06_Blob与轮廓分析.md#selectshape形状选择)：对分割区域按形状特征进一步筛选。

## Watershed（分水岭分割）

### 核心含义
分水岭分割算子基于标记的分水岭算法（watershed）将图像分割为多个互不重叠的区域。该算法将图像视为地形表面，灰度值代表海拔，通过"注水"过程在山谷之间建立分水岭边界，从而将不同目标分离开来。

适用于相互粘连或接触的目标分离场景，例如细胞分割、粘连工件分离等。

### 原理简述
算子首先对输入图像进行高斯模糊（`sigma` 控制平滑程度），然后基于距离变换或灰度极值生成种子标记点（`minDist` 控制种子点之间的最小距离），最后调用 OpenCV `cv::watershed` 函数以这些标记为起点进行分水岭演化。

分水岭算法的核心思想是：从每个种子标记点开始，逐步向低灰度方向"淹没"，当不同标记的淹没区域相遇时即形成分水岭边界。`minDist` 越大，种子点越稀疏，分割区域越少但越稳定。

### 适用场景
- 场景1：粘连细胞或颗粒的分离计数。
- 场景2：接触式工件边界划分，如紧贴的圆形零件。
- 场景3：复杂前景中多个目标的区域划分。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| minDist | 种子标记距离 | Int | 20 | 5 ~ 200 | px | 种子点间最小距离，步长 5 |
| sigma | 高斯模糊 sigma | Double | 1.5 | 0.1 ~ 10 | - | 分割前高斯滤波标准差，步长 0.1 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。建议输入二值化或对比度较高的图像以获得更好的种子点。
- **输出**：
  - `regions`（Region[]）：分水岭区域，类型为 Region 数组，描述为"分水岭分割结果"。

### 使用示例
分离粘连的圆形零件：
```json
{
  "type": "Watershed",
  "params": {
    "minDist": 30,
    "sigma": 2.0
  }
}
```
步骤说明：先对图像二值化得到前景 mask，再调用 Watershed，`minDist=30` 保证种子点间隔足够区分相邻零件，`sigma=2.0` 增强平滑以减少过分割。

### 注意事项
- 分水岭算法容易产生过分割，适当增大 `sigma` 或 `minDist` 可缓解。
- 输入图像质量直接影响种子点生成，建议先做形态学开闭运算去除噪点。
- 当目标间无明显灰度边界时，分割效果会下降，可考虑结合距离变换预处理。

### 关联算子
- [Threshold](#threshold阈值分割)：通常先二值化生成分水岭输入。
- [DistancePp](09_几何测量.md#distancepp点到点距离)：配合距离变换可优化种子点位置。
- [ContourAnalyze](06_Blob与轮廓分析.md#contouranalyze轮廓分析)：分割后提取各区域轮廓进行特征分析。

## RegionGrowing（区域生长）

### 核心含义
区域生长算子基于种子点的区域生长分割方法，从指定的种子点出发，将与种子点灰度相似的相邻像素逐步合并到同一区域，最终形成连通的生长区域。

该算子适用于目标灰度相对均匀且与背景有一定对比度的场景，用户可通过指定种子点位置精确控制生长起点。

### 原理简述
算子从 `(seedX, seedY)` 处的像素开始，检查其邻域像素（通常为 8 连通），若邻域像素与种子点（或已生长区域）的灰度差小于等于 `tolerance`，则将其纳入当前区域并继续向外扩展，直到没有满足条件的新像素为止。

生长准则可表示为：对于候选像素 `p` 和种子灰度 `g_seed`，当 `|g(p) - g_seed| <= tolerance` 时纳入区域。`tolerance` 越大，生长范围越广，但容易溢出到背景。

### 适用场景
- 场景1：医学图像中器官或组织的区域分割。
- 场景2：工业图像中目标灰度均匀、背景对比明显的区域提取。
- 场景3：需要从特定位置开始提取连通区域的交互式分割。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| seedX | 种子 X | Int | 320 | 0 ~ 8192 | px | 种子点 X 坐标，步长 1 |
| seedY | 种子 Y | Int | 240 | 0 ~ 8192 | px | 种子点 Y 坐标，步长 1 |
| tolerance | 灰度容差 | Int | 10 | 1 ~ 255 | - | 相邻像素灰度差阈值，步长 1 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。种子点必须在图像有效范围内。
- **输出**：
  - `region`（Region）：生长区域，类型为 Region，描述为"区域生长结果"。

### 使用示例
从图像中心生长提取均匀灰度目标：
```json
{
  "type": "RegionGrowing",
  "params": {
    "seedX": 320,
    "seedY": 240,
    "tolerance": 15
  }
}
```
步骤说明：将种子点定位在目标中心 `(320,240)`，设置 `tolerance=15` 允许灰度波动 ±15 的像素被纳入区域，适用于灰度均匀的工件提取。

### 注意事项
- 种子点坐标必须在图像范围内（`seedX < 图像宽度`，`seedY < 图像高度`），否则会报错。
- `tolerance` 过大会导致生长溢出到背景，过小则区域不完整，需根据目标与背景的灰度差调整。
- 该算子对噪声敏感，建议先做高斯滤波预处理。

### 关联算子
- [Threshold](#threshold阈值分割)：可作为区域生长的前置二值化步骤。
- [AreaCenter](06_Blob与轮廓分析.md#areacenter面积中心点)：生长后计算区域重心用于定位。
- [SelectShape](06_Blob与轮廓分析.md#selectshape形状选择)：对生长结果按形状特征筛选。

## Threshold（阈值分割）

### 核心含义
阈值分割算子对灰度图像进行阈值化处理，是最基础的图像分割方法。它将像素灰度与给定阈值比较，根据比较结果将像素分为前景或背景，支持二值化、反向二值化、截断、归零、反向归零五种模式。

该算子计算速度极快，适用于光照均匀、目标与背景灰度差异明显的场景，是大多数视觉流程的第一步分割操作。

### 原理简述
算子调用 OpenCV `cv::threshold` 函数，根据 `method` 参数选择阈值化方式：

- `BINARY`：`dst = (src > threshold) ? maxValue : 0`
- `BINARY_INV`：`dst = (src > threshold) ? 0 : maxValue`
- `TRUNC`：`dst = (src > threshold) ? threshold : src`
- `TOZERO`：`dst = (src > threshold) ? src : 0`
- `TOZERO_INV`：`dst = (src > threshold) ? 0 : src`

其中 `threshold` 为分割阈值，`maxValue` 为二值化后的最大像素值（通常为 255）。

### 适用场景
- 场景1：光照均匀条件下工件前景提取。
- 场景2：二值化预处理，为后续连通域分析或轮廓检测做准备。
- 场景3：简单 OCR 或条码识别前的图像二值化。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| threshold | 阈值 | Double | 128 | 0 ~ 255 | - | 分割阈值（0-255），步长 1 |
| maxValue | 最大值 | Double | 255 | 0 ~ 255 | - | 二值化后的最大像素值，步长 1 |
| method | 方法 | Enum | BINARY | BINARY / BINARY_INV / TRUNC / TOZERO / TOZERO_INV | - | OpenCV 阈值化方法 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。若为彩色图像需先转换为灰度图。
- **输出**：
  - `region`（Region）：阈值区域，类型为 Region，描述为"阈值分割区域"。

### 使用示例
二值化提取亮色目标：
```json
{
  "type": "Threshold",
  "params": {
    "threshold": 128,
    "maxValue": 255,
    "method": "BINARY"
  }
}
```
步骤说明：将灰度大于 128 的像素置为 255（白色），其余置为 0（黑色），得到二值化前景区域，适用于亮目标暗背景场景。

反向二值化提取暗色目标：
```json
{
  "type": "Threshold",
  "params": {
    "threshold": 100,
    "maxValue": 255,
    "method": "BINARY_INV"
  }
}
```

### 注意事项
- `method` 为 `TRUNC`、`TOZERO`、`TOZERO_INV` 时输出不是二值图像，而是灰度图像，后续算子需注意输入要求。
- 阈值选择对结果影响极大，光照不均时建议改用 [DynThreshold](#dynthreshold动态阈值)。
- `maxValue` 仅对 `BINARY` 和 `BINARY_INV` 方法有效。

### 关联算子
- [DynThreshold](#dynthreshold动态阈值)：光照不均时替代全局阈值。
- [Connection](06_Blob与轮廓分析.md#connection连通域分析)：二值化后提取连通域。
- [ContourAnalyze](06_Blob与轮廓分析.md#contouranalyze轮廓分析)：基于二值图提取轮廓。
- [FindNccModel](08_匹配定位.md#findnccmodelncc匹配)：阈值化结果可作为匹配的预处理。
