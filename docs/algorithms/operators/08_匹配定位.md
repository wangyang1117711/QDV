## FindNccModel（NCC 匹配）

### 核心含义
NCC（Normalized Cross Correlation，归一化互相关）匹配算子基于灰度相关性在图像中定位模板目标。该算子通过计算模板与图像各位置的归一化互相关分数，找到与模板最相似的目标位置。

NCC 匹配对线性光照变化有一定鲁棒性，但对旋转和缩放敏感，适用于目标姿态变化较小的场景。

### 原理简述
算子基于 OpenCV 模板匹配框架，使用归一化互相关系数作为相似度度量。对于模板 `T` 和图像位置 `I` 处的子图：

```
NCC(x,y) = Σ[(I - Ī)(T - T̄)] / sqrt(Σ(I-Ī)² · Σ(T-T̄)²)
```

其中 `Ī` 和 `T̄` 分别为子图和模板的灰度均值。NCC 值范围为 [-1, 1]，值越接近 1 表示匹配度越高。

算子在图像上滑动模板，计算每个位置的 NCC 分数，返回分数大于 `threshold` 的匹配位置。归一化操作使 NCC 对线性光照变化（`I' = a·I + b`）不变。

### 适用场景
- 场景1：目标姿态固定的工件定位，如传送带上固定方向的产品。
- 场景2：模板印刷图案定位，如 Logo、标签识别。
- 场景3：简单目标跟踪，目标无旋转和缩放变化。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| template | 模板图像路径 | String | "" | - | - | 模板图像路径 |
| threshold | 匹配阈值 | Double | 0.7 | -1 ~ 1 | - | NCC 分数阈值（-1~1），步长 0.05 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。模板图像应为灰度图，尺寸小于待搜索图像。
- **输出**：
  - `matches`（Match[]）：匹配结果，类型为 Match 数组，描述为"NCC模板匹配结果"。

### 使用示例
定位传送带上的产品：
```json
{
  "type": "FindNccModel",
  "params": {
    "template": "templates/product.png",
    "threshold": 0.8
  }
}
```
步骤说明：加载产品模板图像，设置匹配阈值 0.8（NCC 分数 ≥ 0.8 视为命中），在搜索图像中找到与模板最相似的位置。

### 注意事项
- NCC 匹配对旋转和缩放敏感，若目标有旋转需改用 [FindShapeModel](#findshapemodel形状匹配)。
- `threshold` 取值范围 -1~1，推荐 0.7~0.9，过低会产生误匹配，过高可能漏检。
- 模板图像尺寸不宜过大（建议小于 200×200），否则匹配速度会显著下降。
- 模板应从典型场景图像中裁剪，确保与实际目标外观一致。

### 关联算子
- [FindShapeModel](#findshapemodel形状匹配)：支持旋转和缩放的形状匹配，适用于姿态变化的场景。
- [TemplateMatch](#templatematch模板匹配)：支持 6 种匹配方法的模板匹配，灵活性更高。
- [ContourMatch](#contourmatch轮廓匹配)：基于轮廓的匹配，对光照变化更鲁棒。
- [Threshold](05_图像分割.md#threshold阈值分割)：匹配定位后可配合阈值分割提取目标区域。

## FindShapeModel（形状匹配）

### 核心含义
形状匹配算子基于形状模板进行匹配定位，具有旋转和缩放不变性。该算子（类似 HALCON `find_shape_model`）通过提取模板的边缘形状特征进行匹配，而非直接比较灰度值，因此对光照变化有更强的鲁棒性。

形状匹配是工业视觉中最常用的定位方法之一，适用于目标姿态不确定的场景。

### 原理简述
算子的匹配流程：

1. **模板创建**：从模板图像中提取边缘点（基于梯度），生成形状模板。形状模板记录各边缘点相对于模板中心的极坐标 `(r, θ)` 及梯度方向。
2. **搜索**：在搜索图像中同样提取边缘点，将形状模板在搜索图像上以不同角度（`angleStart` ~ `angleStart + angleExtent`）和缩放（`scaleMin` ~ `scaleMax`）进行匹配。
3. **评分**：计算形状模板与搜索图像边缘点的匹配程度，匹配分数 = 匹配的边缘点数 / 模板边缘点总数。
4. **筛选**：返回匹配分数大于 `threshold` 的位置，最多返回 `numMatches` 个结果。

形状匹配基于边缘梯度方向，对线性光照变化和部分遮挡有较好的鲁棒性。

### 适用场景
- 场景1：目标有旋转变化的定位，如任意方向的零件。
- 场景2：目标有缩放变化的定位，如不同距离的相机拍摄。
- 场景3：光照变化场景下的稳定定位，形状特征比灰度特征更鲁棒。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| template | 模板图像路径 | String | "" | - | - | 用于创建形状模板的图像 |
| threshold | 匹配阈值 | Double | 0.7 | 0 ~ 1 | - | 匹配分数阈值（0~1），步长 0.05 |
| angleStart | 起始角度 | Double | -180 | -360 ~ 360 | ° | 起始旋转角，步长 1 |
| angleExtent | 角度范围 | Double | 360 | 0 ~ 360 | ° | 旋转搜索范围，步长 1 |
| scaleMin | 最小缩放 | Double | 0.9 | 0.1 ~ 2 | - | 最小缩放比例，步长 0.1 |
| scaleMax | 最大缩放 | Double | 1.1 | 0.1 ~ 2 | - | 最大缩放比例，步长 0.1 |
| numMatches | 最大匹配数 | Int | 1 | 1 ~ 100 | - | 最多返回的匹配结果数，步长 1 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。模板图像应为灰度图，包含清晰的边缘特征。
- **输出**：
  - `matches`（Match[]）：匹配结果，类型为 Match 数组，描述为"形状模板匹配结果"。

### 使用示例
全角度搜索目标：
```json
{
  "type": "FindShapeModel",
  "params": {
    "template": "templates/part.png",
    "threshold": 0.6,
    "angleStart": -180,
    "angleExtent": 360,
    "scaleMin": 0.9,
    "scaleMax": 1.1,
    "numMatches": 5
  }
}
```
步骤说明：加载零件模板，匹配阈值 0.6，全角度搜索（-180°~180°），缩放范围 0.9~1.1，最多返回 5 个匹配结果。

限定角度范围搜索：
```json
{
  "type": "FindShapeModel",
  "params": {
    "template": "templates/part.png",
    "threshold": 0.7,
    "angleStart": -30,
    "angleExtent": 60,
    "scaleMin": 1.0,
    "scaleMax": 1.0,
    "numMatches": 1
  }
}
```
步骤说明：限定角度范围 -30°~30°（搜索 60°），无缩放变化，可显著提升搜索速度。

### 注意事项
- 角度范围和缩放范围越大，搜索时间越长，建议根据实际场景尽量缩小范围。
- `scaleMin` 必须小于等于 `scaleMax`，且两者都不应过大（>2 会显著增加搜索时间）。
- 模板图像应包含足够清晰的边缘特征，边缘模糊会导致匹配失败。
- `numMatches` 设置过大时，弱匹配结果可能不可靠，建议配合 `threshold` 使用。
- 模板图像尺寸建议适中，过大创建模板慢，过小特征不足。

### 关联算子
- [FindNccModel](#findnccmodelncc匹配)：无旋转变化时 NCC 匹配速度更快。
- [TemplateMatch](#templatematch模板匹配)：不支持旋转但方法更灵活。
- [ContourMatch](#contourmatch轮廓匹配)：基于轮廓的匹配，适用于复杂形状。
- [EdgesSubPix](07_特征提取与识别.md#edgessubpix亚像素边缘)：形状匹配基于边缘，亚像素边缘可提升模板质量。
- [GeometryMeasure](09_几何测量.md#geometrymeasure几何测量)：匹配定位后基于位置进行测量。

## TemplateMatch（模板匹配）

### 核心含义
模板匹配算子基于 OpenCV `cv::matchTemplate` 函数实现模板匹配定位，支持 6 种匹配方法。该算子通过在搜索图像上滑动模板并计算相似度得分来找到最佳匹配位置。

模板匹配是最基础的匹配方法，计算简单但对旋转和缩放敏感，适用于目标姿态固定的快速定位场景。

### 原理简述
算子在搜索图像上以滑动窗口方式遍历每个位置，将模板与覆盖区域的子图按指定方法计算相似度得分：

- **SQDIFF（平方差）**：`Σ(T-I)²`，值越小越匹配。
- **SQDIFF_NORMED（归一化平方差）**：`Σ(T-I)² / sqrt(ΣT²·ΣI²)`，值越小越匹配，范围 [0,1]。
- **CCORR（相关）**：`ΣT·I`，值越大越匹配。
- **CCORR_NORMED（归一化相关）**：`ΣT·I / sqrt(ΣT²·ΣI²)`，值越大越匹配，范围 [0,1]。
- **CCOEFF（相关系数）**：`Σ(T-T̄)(I-Ī)`，值越大越匹配。
- **CCOEFF_NORMED（归一化相关系数）**：`Σ(T-T̄)(I-Ī) / sqrt(Σ(T-T̄)²·Σ(I-Ī)²)`，值越大越匹配，范围 [-1,1]。

其中 SQDIFF 系列值越小越匹配（阈值判断为 `score ≤ threshold`），其余方法值越大越匹配（`score ≥ threshold`）。

### 适用场景
- 场景1：目标姿态固定的快速定位，如固定夹具上的工件。
- 场景2：印刷品缺陷检测中的模板对齐。
- 场景3：简单目标跟踪，无旋转和缩放变化。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| template | 模板图像路径 | String | "" | - | - | 10x10 到 5000x5000 之间的灰度图，最大 50MB |
| threshold | 匹配阈值 | Double | 0.8 | 0 ~ 1 | - | 分数 ≥ 阈值 视为命中，步长 0.05 |
| method | 匹配方法 | Enum | CCOEFF_NORMED | SQDIFF / SQDIFF_NORMED / CCORR / CCORR_NORMED / CCOEFF / CCOEFF_NORMED | - | 推荐 CCOEFF_NORMED（归一化相关系数） |

### 输入输出
- **输入**：单通道灰度图像（Mat）。模板图像尺寸需小于搜索图像，范围 10×10 ~ 5000×5000，最大 50MB。
- **输出**：
  - `matches`（Match[]）：匹配结果，类型为 Match 数组，描述为"模板匹配结果"。

### 使用示例
使用归一化相关系数匹配：
```json
{
  "type": "TemplateMatch",
  "params": {
    "template": "templates/target.png",
    "threshold": 0.85,
    "method": "CCOEFF_NORMED"
  }
}
```
步骤说明：加载目标模板，使用归一化相关系数方法（推荐），阈值 0.85，在搜索图像中找到匹配度最高的位置。

使用平方差方法匹配：
```json
{
  "type": "TemplateMatch",
  "params": {
    "template": "templates/target.png",
    "threshold": 0.1,
    "method": "SQDIFF_NORMED"
  }
}
```
步骤说明：使用归一化平方差方法，阈值 0.1（值越小越匹配），适用于对匹配精度要求高的场景。

### 注意事项
- `SQDIFF` 和 `SQDIFF_NORMED` 方法值越小越匹配，阈值应设置较小（如 0.1）；其他方法值越大越匹配，阈值应设置较大（如 0.8）。
- 模板匹配不支持旋转和缩放，目标姿态变化时需改用 [FindShapeModel](#findshapemodel形状匹配)。
- 推荐使用 `CCOEFF_NORMED` 方法，它对线性光照变化不变且结果标准化。
- 模板尺寸过大时匹配速度会显著下降，建议模板尺寸不超过搜索图像的 1/4。
- 模板图像需为灰度图，彩色图像需先转换。

### 关联算子
- [FindNccModel](#findnccmodelncc匹配)：NCC 匹配本质是 `CCOEFF_NORMED` 方法的封装。
- [FindShapeModel](#findshapemodel形状匹配)：支持旋转和缩放的进阶匹配方法。
- [ContourMatch](#contourmatch轮廓匹配)：基于轮廓的匹配，对光照变化更鲁棒。
- [Threshold](05_图像分割.md#threshold阈值分割)：匹配定位后配合阈值分割提取目标。

## ContourMatch（轮廓匹配）

### 核心含义
轮廓匹配算子基于模板轮廓在图像中匹配目标，返回匹配结果列表。与基于灰度的匹配不同，轮廓匹配利用目标的形状轮廓特征进行匹配，对光照变化和颜色变化具有更强的鲁棒性。

该算子支持三种匹配方法（I1、I2、I3），可控制最大匹配数和最小面积，适用于复杂场景下的多目标匹配。

### 原理简述
算子的匹配流程：

1. **模板轮廓加载**：从模板文件中加载预定义的轮廓数据（轮廓点的坐标序列）。
2. **搜索图像轮廓提取**：在搜索图像中提取边缘轮廓（基于 Canny 或阈值化）。
3. **轮廓匹配**：将模板轮廓与搜索图像中的每条轮廓进行匹配，计算 Hu 矩或其他形状描述子的相似度。Hu 矩具有平移、旋转、缩放不变性。
4. **筛选**：根据 `threshold` 过滤匹配分数，根据 `minArea` 过滤过小目标，最多返回 `maxMatches` 个结果。

三种匹配方法（`matchMethod`）：
- **I1**：基于 Hu 矩的第一种距离度量（`CV_CONTOURS_MATCH_I1`）。
- **I2**：基于 Hu 矩的第二种距离度量（`CV_CONTOURS_MATCH_I2`）。
- **I3**：基于 Hu 矩的第三种距离度量（`CV_CONTOURS_MATCH_I3`）。

Hu 矩由 7 个不变矩组成，通过对轮廓的归一化中心矩进行非线性组合得到。

### 适用场景
- 场景1：目标形状特征明显但光照/颜色变化大的场景。
- 场景2：多目标匹配，需要在图像中找到多个相同形状的目标。
- 场景3：基于形状的缺陷检测，比较目标轮廓与标准轮廓的偏差。

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| templatePath | 模板路径 | String | "" | - | - | 轮廓模板文件路径 |
| threshold | 匹配阈值 | Double | 0.8 | - | - | 匹配分数阈值 |
| maxMatches | 最大匹配数 | Int | 10 | - | - | 返回的最大匹配数量 |
| matchMethod | 匹配方法 | Bool | I1 | - | - | 轮廓匹配方法（可选值：I1 / I2 / I3） |
| minArea | 最小面积 | Double | 100 | - | - | 匹配目标的最小面积 |

### 输入输出
- **输入**：单通道灰度图像（Mat）。图像中应包含清晰的边缘轮廓。
- **输出**：
  - `matches`（Match[]）：匹配结果，类型为 Match 数组，描述为"匹配结果列表"。
  - `matchCount`（int）：匹配数量，类型为 int，描述为"匹配到的目标数量"。
  - `bestScore`（float）：最佳分数，类型为 float，描述为"最高匹配分数"。

### 使用示例
多目标轮廓匹配：
```json
{
  "type": "ContourMatch",
  "params": {
    "templatePath": "templates/contour.json",
    "threshold": 0.75,
    "maxMatches": 10,
    "matchMethod": "I1",
    "minArea": 200
  }
}
```
步骤说明：加载轮廓模板，匹配阈值 0.75，最多返回 10 个匹配结果，使用 I1 方法，过滤面积小于 200 像素² 的目标。

### 注意事项
- `matchMethod` 可选值为 `I1`、`I2`、`I3`，三种 Hu 矩距离度量方式，通常 I1 效果最好。
- `threshold` 的合理范围取决于匹配方法，Hu 矩距离越小表示越相似，具体阈值需通过实验调整。
- 轮廓模板文件需预先准备好，包含标准轮廓的坐标数据。
- `minArea` 用于过滤噪点和过小目标，避免误匹配。
- 输入图像质量直接影响轮廓提取，建议先做边缘检测或二值化预处理。
- 与 [FindShapeModel](#findshapemodel形状匹配) 相比，轮廓匹配更灵活但速度可能较慢。

### 关联算子
- [ContourAnalyze](06_Blob与轮廓分析.md#contouranalyze轮廓分析)：提取搜索图像的轮廓作为匹配输入。
- [EdgesSubPix](07_特征提取与识别.md#edgessubpix亚像素边缘)：提供高质量轮廓用于模板创建。
- [FindShapeModel](#findshapemodel形状匹配)：另一种基于形状的匹配方法，性能更高。
- [SelectShape](06_Blob与轮廓分析.md#selectshape形状选择)：匹配后按形状特征筛选结果。
- [GeometryMeasure](09_几何测量.md#geometrymeasure几何测量)：基于匹配位置进行几何测量。
