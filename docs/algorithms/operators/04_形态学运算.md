## Closing（闭运算）

### 核心含义
对图像进行形态学闭运算，即"先膨胀后腐蚀"。闭运算能够填充目标区域内部的小孔洞和狭窄缝隙，连接相邻的断裂区域，同时保持目标整体尺寸和形状基本不变。

闭运算是形态学最常用的操作之一，常用于填补二值化后目标内部的空洞、连接断裂的边缘、平滑目标边界。与开运算互为对偶操作。

### 原理简述
闭运算的定义：

```
Closing(A) = Erosion(Dilation(A))
```

即先用结构元素 B 对图像 A 做膨胀（Dilation），再用同一结构元素做腐蚀（Erosion）。

- **膨胀**：将结构元素覆盖区域内所有像素置为前景，可填补孔洞、连接断裂
- **腐蚀**：将结构元素覆盖区域内只要存在背景就置为背景，可去除细小突出

先膨胀后腐蚀的净效果是：填补了比结构元素小的孔洞与缝隙，但目标整体尺寸基本恢复。底层调用 `cv::morphologyEx` 且 `op=cv::MORPH_CLOSE`。

结构元素形状由 `shape` 决定（rectangle / circle / cross），尺寸由 `structWidth × structHeight` 决定。

### 适用场景
- 场景1：填补孔洞——二值化后目标内部出现小黑洞，用闭运算填充
- 场景2：连接断裂——边缘检测得到的断裂边缘通过闭运算连接为连续轮廓
- 场景3：边界平滑——目标边缘有细小凹陷，闭运算可平滑外边界

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| structWidth | 结构元宽度 | Int | 5 | 1 ~ 51 | px | 结构元素宽度（奇数），步长 2 |
| structHeight | 结构元高度 | Int | 5 | 1 ~ 51 | px | 结构元素高度（奇数），步长 2 |
| shape | 形状 | Enum | rectangle | rectangle / circle / cross | - | 结构元素形状：矩形 / 圆形 / 十字 |

### 输入输出
- **输入**：二值图或灰度图（二值图效果最显著）
- **输出**：`image`（闭运算结果，类型 Mat）——闭运算后的图像

### 使用示例
典型配置——5×5 矩形结构元闭运算填补小孔：

```json
{
  "type": "Closing",
  "params": {
    "structWidth": 5,
    "structHeight": 5,
    "shape": "rectangle"
  }
}
```

步骤说明：
1. 前置阈值分割或 ColorDetect 得到二值图
2. Closing 设 `structWidth=5, structHeight=5`，填补直径小于 5 像素的孔洞
3. 若仍有大孔洞，逐步增大结构元尺寸（如 9、11）

### 注意事项
- 结构元尺寸应略大于待填补的孔洞尺寸，过大可能导致相邻目标粘连
- 圆形结构元对圆形目标更友好，矩形结构元对水平/垂直结构更有效
- 闭运算会轻微改变目标边界，对尺寸精度要求高的测量任务应谨慎使用

### 关联算子
- **Opening**：对偶操作，去除小白噪点而非填补黑洞
- **Dilation / Erosion**：闭运算的两个组成步骤
- **BottomHat**：闭运算结果减原图，用于提取暗细节

## BottomHat（底帽变换）

### 核心含义
对图像进行底帽（Bottom Hat）变换，即"闭运算结果减去原图"。底帽变换提取原图中比周围暗的小细节，常用于检测亮背景中的暗目标（如亮色背景上的暗色污点、划痕）。

与 TopHat 互为对偶操作：TopHat 检测亮细节，BottomHat 检测暗细节。两者都属于形态学 Top-Hat 系列，用于背景非均匀时的细节增强。

### 原理简述
底帽变换的定义：

```
BottomHat(A) = Closing(A) − A
```

即用闭运算结果（填补孔洞后的图像）减去原图。由于闭运算填补了暗孔洞，相减后这些暗区域被突出为正值，而亮背景区域相减后接近 0。

结果图像中：
- 原图中的暗细节（孔洞、划痕）变为亮像素
- 亮背景区域变为暗像素
- 便于后续阈值分割提取暗目标

底层调用 `cv::morphologyEx` 且 `op=cv::MORPH_BLACKHAT`。

### 适用场景
- 场景1：暗污点检测——亮色产品表面的暗色污点、黑点
- 场景2：划痕检测——亮背景上的暗划痕（结构元方向需匹配划痕方向）
- 场景3：非均匀背景下的暗目标提取——背景照明不均，直接阈值失败时

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| structWidth | 结构元宽度 | Int | 7 | 1 ~ 101 | px | 结构元素宽度（奇数），步长 2 |
| structHeight | 结构元高度 | Int | 7 | 1 ~ 101 | px | 结构元素高度（奇数），步长 2 |

### 输入输出
- **输入**：灰度图（建议 8 位）
- **输出**：`image`（底帽结果，类型 Mat）——底帽变换结果（暗细节变为亮像素）

### 使用示例
典型配置——7×7 结构元检测暗污点：

```json
{
  "type": "BottomHat",
  "params": {
    "structWidth": 7,
    "structHeight": 7
  }
}
```

步骤说明：
1. 前置 GaussFilter 做轻度去噪
2. BottomHat 设 `structWidth=7, structHeight=7`，结构元略大于待检测暗点尺寸
3. 输出图中暗点变为亮像素，连接阈值分割或 Blob 分析

### 注意事项
- 结构元尺寸应略大于待检测暗细节的尺寸，过小则无法突出，过大则可能误检
- 底帽结果动态范围较小，常配合 ScaleImage 拉伸对比度
- 本算子仅支持矩形结构元，无法选择 circle / cross 形状

### 关联算子
- **TopHat**：对偶操作，检测亮细节
- **Closing**：底帽变换的核心组成部分
- **ScaleImage**：底帽结果常需拉伸后才能有效分割

## Erosion（腐蚀）

### 核心含义
对图像进行形态学腐蚀操作，将每个像素替换为其邻域内的最小值。腐蚀会收缩亮区域（前景）、扩展暗区域（背景），能够消除细小的亮噪点、断开狭窄连接、平滑目标边界。

腐蚀是形态学最基础的两个操作之一（另一个为膨胀），是开运算、Top-Hat 等复合操作的组成单元。

### 原理简述
腐蚀的定义：

```
Erosion(A, B)(x,y) = min{ A(x+i, y+j) | (i,j) ∈ B }
```

即用结构元素 B 扫描图像 A，将中心像素替换为 B 覆盖区域内的最小像素值。对二值图而言，只要结构元素覆盖范围内存在背景像素，中心就置为背景。

底层调用 `cv::erode`，结构元素由 `shape` 和 `structWidth × structHeight` 决定。`iterations` 控制重复腐蚀次数，等价于使用更大结构元但计算更可控。

### 适用场景
- 场景1：去除小白噪点——二值图中的细小亮点噪声
- 场景2：断开狭窄连接——两个目标通过细线相连，腐蚀可断开
- 场景3：尺寸缩减——精确控制目标缩小若干像素

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| structWidth | 结构元宽度 | Int | 3 | 1 ~ 51 | px | 结构元素宽度（奇数），步长 2 |
| structHeight | 结构元高度 | Int | 3 | 1 ~ 51 | px | 结构元素高度（奇数），步长 2 |
| shape | 形状 | Enum | rectangle | rectangle / circle / cross | - | 结构元素形状：矩形 / 圆形 / 十字 |
| iterations | 迭代次数 | Int | 1 | 1 ~ 10 | - | 重复腐蚀的次数，步长 1 |

### 输入输出
- **输入**：二值图或灰度图
- **输出**：`image`（腐蚀结果，类型 Mat）——腐蚀后的图像

### 使用示例
典型配置——3×3 矩形腐蚀去噪：

```json
{
  "type": "Erosion",
  "params": {
    "structWidth": 3,
    "structHeight": 3,
    "shape": "rectangle",
    "iterations": 1
  }
}
```

### 注意事项
- 腐蚀会缩小目标尺寸，对尺寸精度要求高的任务需控制 `iterations`
- 圆形结构元腐蚀结果更平滑，适合圆形目标处理
- `iterations` 过大会导致目标消失，一般不超过 3-5 次

### 关联算子
- **Dilation**：对偶操作，扩展亮区域
- **Opening**：先腐蚀后膨胀，去噪同时保持尺寸
- **TopHat**：原图减开运算，提取亮细节

## Opening（开运算）

### 核心含义
对图像进行形态学开运算，即"先腐蚀后膨胀"。开运算能够消除细小的亮噪点、断开狭窄连接、平滑目标边界，同时保持目标整体尺寸和形状基本不变。

开运算是形态学最常用的操作之一，常用于二值图去噪、去除细小突出。与闭运算互为对偶操作。

### 原理简述
开运算的定义：

```
Opening(A) = Dilation(Erosion(A))
```

即先用结构元素 B 对图像 A 做腐蚀（Erosion），再用同一结构元素做膨胀（Dilation）。

- **腐蚀**：去除比结构元素小的亮区域
- **膨胀**：恢复剩余目标的尺寸

先腐蚀后膨胀的净效果是：消除了比结构元素小的亮噪点和突出，但目标整体尺寸基本恢复。底层调用 `cv::morphologyEx` 且 `op=cv::MORPH_OPEN`。

### 适用场景
- 场景1：去除小白噪点——二值图中的椒盐亮点噪声
- 场景2：断开狭窄连接——两目标通过细线相连，开运算可断开
- 场景3：平滑目标边界——去除目标边缘的毛刺与不规则突出

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| structWidth | 结构元宽度 | Int | 5 | 1 ~ 51 | px | 结构元素宽度（奇数），步长 2 |
| structHeight | 结构元高度 | Int | 5 | 1 ~ 51 | px | 结构元素高度（奇数），步长 2 |
| shape | 形状 | Enum | rectangle | rectangle / circle / cross | - | 结构元素形状：矩形 / 圆形 / 十字 |

### 输入输出
- **输入**：二值图或灰度图（二值图效果最显著）
- **输出**：`image`（开运算结果，类型 Mat）——开运算后的图像

### 使用示例
典型配置——5×5 矩形结构元开运算去噪：

```json
{
  "type": "Opening",
  "params": {
    "structWidth": 5,
    "structHeight": 5,
    "shape": "rectangle"
  }
}
```

步骤说明：
1. 前置 ColorDetect 或 Threshold 得到二值图
2. Opening 设 `structWidth=5, structHeight=5`，去除直径小于 5 像素的亮点噪声
3. 若仍存在中等尺寸噪声，逐步增大结构元（如 7、9）

### 注意事项
- 结构元尺寸应略大于待去除的噪点尺寸，过大会误删小目标
- 圆形结构元对圆形目标更友好，避免方向性偏差
- 开运算会轻微改变目标边界，但对整体尺寸影响小于单独腐蚀

### 关联算子
- **Closing**：对偶操作，填补黑洞而非去除亮点
- **Erosion / Dilation**：开运算的两个组成步骤
- **TopHat**：原图减开运算，提取亮细节

## TopHat（顶帽变换）

### 核心含义
对图像进行顶帽（Top Hat）变换，即"原图减去开运算结果"。顶帽变换提取原图中比周围亮的小细节，常用于检测暗背景中的亮目标（如暗色表面上的亮色划痕、亮点缺陷）。

与 BottomHat 互为对偶操作：TopHat 检测亮细节，BottomHat 检测暗细节。两者都属于形态学 Top-Hat 系列，用于背景非均匀时的细节增强。

### 原理简述
顶帽变换的定义：

```
TopHat(A) = A − Opening(A)
```

即用原图减去开运算结果（去除亮噪点后的图像）。由于开运算消除了亮细节，相减后这些亮区域被突出为正值，而暗背景区域相减后接近 0。

结果图像中：
- 原图中的亮细节（划痕、亮点）保持为亮像素
- 暗背景区域变为暗像素
- 便于后续阈值分割提取亮目标

底层调用 `cv::morphologyEx` 且 `op=cv::MORPH_TOPHAT`。

### 适用场景
- 场景1：亮划痕检测——暗色产品表面的亮色划痕
- 场景2：亮点缺陷检测——暗背景上的亮点、反光点
- 场景3：非均匀背景下的亮目标提取——背景照明不均，直接阈值失败时

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| structWidth | 结构元宽度 | Int | 7 | 1 ~ 101 | px | 结构元素宽度（奇数），步长 2 |
| structHeight | 结构元高度 | Int | 7 | 1 ~ 101 | px | 结构元素高度（奇数），步长 2 |

### 输入输出
- **输入**：灰度图（建议 8 位）
- **输出**：`image`（顶帽结果，类型 Mat）——顶帽变换结果（亮细节被突出）

### 使用示例
典型配置——7×7 结构元检测亮划痕：

```json
{
  "type": "TopHat",
  "params": {
    "structWidth": 7,
    "structHeight": 7
  }
}
```

步骤说明：
1. 前置 GaussFilter 做轻度去噪
2. TopHat 设 `structWidth=7, structHeight=7`，结构元略大于待检测亮划痕宽度
3. 输出图中划痕保持为亮像素，背景被抑制
4. 连接阈值分割或 Blob 分析提取划痕

### 注意事项
- 结构元尺寸应略大于待检测亮细节的尺寸，过小则无法突出，过大则可能误检
- 顶帽结果动态范围较小，常配合 ScaleImage 拉伸对比度
- 本算子仅支持矩形结构元，无法选择 circle / cross 形状

### 关联算子
- **BottomHat**：对偶操作，检测暗细节
- **Opening**：顶帽变换的核心组成部分
- **ScaleImage**：顶帽结果常需拉伸后才能有效分割

## Dilation（膨胀）

### 核心含义
对图像进行形态学膨胀操作，将每个像素替换为其邻域内的最大值。膨胀会扩展亮区域（前景）、收缩暗区域（背景），能够填补目标内部的小孔洞、连接断裂区域、平滑目标边界。

膨胀是形态学最基础的两个操作之一（另一个为腐蚀），是闭运算、Bottom-Hat 等复合操作的组成单元。

### 原理简述
膨胀的定义：

```
Dilation(A, B)(x,y) = max{ A(x+i, y+j) | (i,j) ∈ B }
```

即用结构元素 B 扫描图像 A，将中心像素替换为 B 覆盖区域内的最大像素值。对二值图而言，只要结构元素覆盖范围内存在前景像素，中心就置为前景。

底层调用 `cv::dilate`，结构元素由 `shape` 和 `structWidth × structHeight` 决定。`iterations` 控制重复膨胀次数，等价于使用更大结构元但计算更可控。

### 适用场景
- 场景1：填补小孔洞——目标内部的小黑洞通过膨胀填充
- 场景2：连接断裂——边缘检测得到的断裂边缘通过膨胀连接
- 场景3：尺寸扩展——精确控制目标扩大若干像素

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|

| shape | 形状 | Enum | rectangle | rectangle / circle / cross | - | 结构元素形状：矩形 / 圆形 / 十字 |
| iterations | 迭代次数 | Int | 1 | 1 ~ 10 | - | 重复膨胀的次数，步长 1 |

### 输入输出
- **输入**：二值图或灰度图
- **输出**：`image`（膨胀结果，类型 Mat）——膨胀后的图像

```json
{
  "type": "Dilation",
  "params": {
    "structWidth": 3,
    "structHeight": 3,
    "shape": "rectangle",
    "iterations": 1
  }
}
```

步骤说明：
1. 前置阈值分割得到二值图

3. 若仍有大孔洞，可增大结构元或增加 `iterations`

- 膨胀会扩大目标尺寸，可能导致相邻目标粘连，需控制 `iterations`
- 圆形结构元膨胀结果更平滑，适合圆形目标处理
