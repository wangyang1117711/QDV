## FftGeneric（FFT变换）

### 核心含义
对图像进行正向或反向快速傅里叶变换，将图像在空间域与频率域之间转换。正向变换把图像分解为不同频率分量的幅值与相位，便于在频域中设计滤波器（如低通去噪、高通锐化、带阻去除周期性干扰）；逆变换则把频域处理后的数据还原回空间域图像。

该算子属于频域滤波子组，是构建频域滤波流水线的基础：用户通常在 FftGeneric 之后连接自定义频域处理（如掩膜相乘），再用 FftGeneric（inverse）还原结果。

### 原理简述
底层调用 OpenCV 的 `cv::dft` / `cv::idft` 完成离散傅里叶变换。正向变换时，先将图像扩展到最优 DFT 尺寸（`cv::getOptimalDFTSize`），构造双通道矩阵（实部+虚部），输出频域复数矩阵；逆向变换时把频域矩阵转回空间域实数图像。

由于 DFT 结果的零频不在中心，实际使用时常配合 `cv::shift`（fftshift）将零频移到中心，便于直观设计与观察频谱。

### 适用场景
- 场景1：周期性噪声去除——图像中存在电网干扰条纹，通过频域带阻滤波消除
- 场景2：频域锐化——设计高通滤波器增强高频细节
- 场景3：频谱分析——观察图像频率分布以指导后续滤波参数选择

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| direction | 变换方向 | Enum | forward | forward / inverse | - | forward=正变换，inverse=逆变换 |

### 输入输出
- **输入**：单通道或三通道图像（建议灰度图，三通道会分通道处理）
- **输出**：`image`（FFT结果，类型 Mat）——傅里叶变换结果

### 使用示例
典型配置——正变换获取频谱后做逆变换还原：

```json
// 步骤1：正变换
{ "type": "FftGeneric", "params": { "direction": "forward" } }

// 步骤2：在频域对结果做处理（如与掩膜相乘）

// 步骤3：逆变换还原
{ "type": "FftGeneric", "params": { "direction": "inverse" } }
```

### 注意事项
- 输入图像尺寸建议为 2 的幂次或经过 `getOptimalDFTSize` 优化，否则 DFT 计算效率下降
- 频域结果为复数矩阵，直接显示为图像时需取幅值并做对数缩放
- 正逆变换必须成对使用，单独逆变换输入非频域数据会得到无意义结果

### 关联算子
- **GaussFilter / MeanImage**：空间域滤波的轻量替代，无需频域转换
- **ImageArithmetic**：可用于频域掩膜相乘
- **ScaleImage**：频谱幅值动态范围大，常用对数缩放显示

## GaussFilter（高斯滤波）

### 核心含义
使用高斯核与图像做卷积，对图像进行平滑处理，主要作用是抑制高斯噪声、降低图像细节层次，为后续边缘检测、阈值分割等操作提供更稳定的输入。

高斯滤波是最常用的线性平滑滤波器之一，相比均值滤波能更好地保留边缘信息，且不会引入明显的方块效应。

### 原理简述
根据 `kernelSize` 和 `sigma` 构造二维高斯核：

G(x,y) = (1 / (2π·σ²)) · exp(−(x²+y²) / (2σ²))

然后用该核与图像做二维卷积。`sigma=0` 时 OpenCV 会根据核大小自动计算合理标准差（`σ = 0.3·((ksize−1)·0.5 − 1) + 0.8`）。底层调用 `cv::GaussianBlur`。

高斯滤波是可分离滤波器（x 方向与 y 方向可分解），因此对大核计算效率较高。

### 适用场景
- 场景1：高斯噪声抑制——传感器噪声近似高斯分布时效果最佳
- 场景2：边缘检测预处理——Canny 前先做高斯平滑避免噪声被误检为边缘
- 场景3：图像金字塔构建——多尺度分析前的高斯降采样平滑

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| kernelSize | 滤波核大小 | Int | 5 | 1 ~ 31 | px | 高斯核尺寸（奇数，推荐 3-11），步长 2 |
| sigma | 标准差 Sigma | Double | 1.0 | 0 ~ 100 | - | 高斯分布标准差，0 表示自动计算，步长 0.1 |

### 输入输出
- **输入**：任意通道数的图像（单通道/三通道均可）
- **输出**：`image`（滤波结果，类型 Mat）——高斯平滑后的图像

### 使用示例
典型配置——5×5 标准高斯平滑：

```json
{
  "type": "GaussFilter",
  "params": {
    "kernelSize": 5,
    "sigma": 1.0
  }
}
```

步骤说明：
1. 在采集算子之后放置 GaussFilter
2. `kernelSize` 设为 5（中等强度平滑）
3. `sigma` 保持 1.0（与核大小匹配）
4. 输出送入 EdgeDetect 做 Canny 边缘检测

### 注意事项
- `kernelSize` 必须为正奇数，偶数会被强制取整或报错
- `sigma` 过大会导致图像严重模糊，边缘信息丢失；通常 `sigma` 与 `kernelSize` 满足 `σ ≈ ksize/6` 关系
- 对椒盐噪声效果不佳，应改用 MedianImage

### 关联算子
- **MedianImage**：椒盐噪声场景的互补选择
- **EdgeDetect**：典型下游，高斯平滑后做 Canny
- **MeanImage**：计算更快的轻量替代，但保边能力较弱

## MeanImage（均值滤波）

### 核心含义
使用矩形均值核与图像做卷积，将每个像素替换为其邻域内像素的算术平均值。这是一种最简单、计算最快的线性平滑滤波器，适用于快速去噪和图像降采样前的预处理。

由于均值核在频域等效于 sinc 函数，存在较明显的振铃效应，因此在保边质量要求高的场景中通常被高斯滤波取代。

### 原理简述
在 `kernelWidth × kernelHeight` 的矩形窗口内，将中心像素值替换为窗口内所有像素的平均值。底层调用 `cv::blur`，其本质是 `cv::boxFilter` 的归一化版本。

均值滤波是可分离滤波器，先按行做一维均值、再按列做一维均值，计算复杂度为 O(N·k) 而非 O(N·k²)。

### 适用场景
- 场景1：快速轻度去噪——对计算耗时敏感、噪声不严重的场景
- 场景2：降采样前预处理——避免下采样引入混叠
- 场景3：背景估计——大核均值滤波可得到图像的背景照明分布

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| kernelWidth | 滤波核宽度 | Int | 9 | 1 ~ 101 | px | 均值核宽度（奇数），步长 2 |
| kernelHeight | 滤波核高度 | Int | 9 | 1 ~ 101 | px | 均值核高度（奇数），步长 2 |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（滤波结果，类型 Mat）——均值平滑后的图像

### 使用示例
典型配置——9×9 均值平滑：

```json
{
  "type": "MeanImage",
  "params": {
    "kernelWidth": 9,
    "kernelHeight": 9
  }
}
```

### 注意事项
- 核尺寸必须为奇数，否则无法定义中心像素
- 核越大平滑越强，但边缘模糊越严重，工业检测中一般不超过 15
- 均值滤波对椒盐噪声无能为力，且会在边缘处产生灰色过渡带

### 关联算子
- **GaussFilter**：保边要求更高时的替代
- **MedianImage**：椒盐噪声场景的首选
- **ScaleImage**：均值后动态范围可能改变，可用缩放恢复

## Emphasize（锐化增强）

### 核心含义
对图像进行锐化增强，突出边缘和细节信息，使模糊的图像看起来更清晰。该算子通过增强高频分量的方式提升局部对比度，常用于图像显示前的视觉优化或为后续特征提取强化边缘。

属于增强与色彩子组，与 ScaleImage 的灰度拉伸不同，Emphasize 侧重于空间频率层面的细节增强。

### 原理简述
基于非锐化掩蔽（Unsharp Masking）原理：

output = original + factor · (original − blur(original))

其中 `blur` 通常为高斯模糊，`factor` 控制增强强度。原始图像减去其模糊版本得到高频细节，再按 `factor` 加回到原图。底层可能调用 `cv::addWeighted` 实现最终融合。

`factor=0` 时无增强，`factor=1` 时为最大增强，过大会放大噪声。

### 适用场景
- 场景1：图像显示优化——采集图像偏软，显示前做轻度锐化
- 场景2：边缘特征强化——为后续 EdgeDetect / Blob 分析增强目标轮廓
- 场景3：低对比度场景——弱光照下细节模糊，通过锐化恢复可辨识度

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| factor | 增强系数 | Double | 0.5 | 0 ~ 1 | - | 增强强度（0=无增强，1=最大增强），步长 0.05 |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（增强结果，类型 Mat）——锐化增强后的图像

### 使用示例
典型配置——中等强度锐化：

```json
{
  "type": "Emphasize",
  "params": {
    "factor": 0.5
  }
}
```

### 注意事项
- `factor` 过大会放大噪声，导致图像出现颗粒感
- 锐化会增强高频分量但不增加信息量，无法恢复实际模糊的细节
- 噪声较大的图像应先做 GaussFilter 去噪再锐化，否则噪声被同步放大

### 关联算子
- **GaussFilter**：先去噪再锐化的典型组合
- **ScaleImage**：可配合做对比度+细节的联合增强
- **EdgeDetect**：锐化后边缘更显著，可降低 Canny 阈值

## ScaleImage（灰度缩放）

### 核心含义
对图像像素值进行线性缩放，公式为 `output = mult · input + add`，用于调整图像的灰度范围与对比度。可将过暗或过亮的图像拉伸到合适的动态范围，或将 16 位图像压缩到 8 位显示。

属于增强与色彩子组，与 Emphasize 的细节增强不同，ScaleImage 是对整体灰度的线性映射。

### 原理简述
对每个像素执行线性变换：

g(x,y) = mult · f(x,y) + add

结果会按图像位深做饱和截断（如 8 位图像截断到 [0,255]）。底层调用 `cv::convertScaleAbs`，同时支持类型转换（如 16U→8U）。

`mult>1` 增强对比度，`0<mult<1` 降低对比度；`add>0` 整体变亮，`add<0` 整体变暗。

### 适用场景
- 场景1：低对比度图像拉伸——将窄灰度范围扩展到 [0,255] 提升可视性
- 场景2：位深转换——16 位相机图像缩放到 8 位用于显示与处理
- 场景3：亮度校正——通过 `add` 偏移补偿光照不均

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| mult | 缩放乘数 | Double | 1.0 | 0.01 ~ 255 | - | 灰度乘法因子，步长 0.1 |
| add | 偏移量 | Double | 0 | -512 ~ 512 | - | 灰度加法偏移，步长 1 |

### 输入输出
- **输入**：任意位深的灰度或彩色图像
- **输出**：`image`（缩放结果，类型 Mat）——灰度缩放后的图像

### 使用示例
典型配置——低对比度图像拉伸 2 倍：

```json
{
  "type": "ScaleImage",
  "params": {
    "mult": 2.0,
    "add": 0
  }
}
```

### 注意事项
- 结果会按目标位深截断，超出范围的值会被饱和到上限或下限
- `mult` 过大会导致高亮区域全部饱和，丢失细节
- 彩色图像对每个通道同步缩放，可能导致色彩偏移

### 关联算子
- **Emphasize**：细节层面的增强，可与 ScaleImage 联用
- **Histogram**：用于分析缩放前后的灰度分布
- **ImageArithmetic**：通过加法/乘法实现类似效果但更灵活

## ImageArithmetic（图像算术）

### 核心含义
对图像执行算术运算（加/减/乘/除）或按位逻辑运算（与/或/异或/取反），支持图像与标量、图像与图像两种模式。常用于背景相减、掩膜融合、图像叠加等场景。

算子通过 `useScalar` 切换运算对象：勾选时与 `scalar` 参数做标量运算，取消时与上一帧缓存图做图像间运算。

### 原理简述
- **add / subtract / multiply / divide**：调用 `cv::add / cv::subtract / cv::multiply / cv::divide`，对应像素级算术运算
- **and / or / xor**：调用 `cv::bitwise_and / cv::bitwise_or / cv::bitwise_xor`，按位逻辑运算
- **not**：调用 `cv::bitwise_not`，对单张图像做按位取反

图像间运算要求两图尺寸与通道数一致；标量运算将标量应用到每个像素每个通道。

### 适用场景
- 场景1：背景相减——当前帧减去背景帧提取运动目标
- 场景2：掩膜融合——通过 bitwise_and 应用掩膜提取感兴趣区域
- 场景3：亮度调整——通过加法标量提升整体亮度

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| operation | 运算 | Enum | add | add / subtract / multiply / divide / and / or / xor / not | - | 加 / 减 / 乘 / 除 / 与 / 或 / 异或 / 取反 |
| scalar | 标量 | Double | 0 | 0 ~ 1000000 | - | 与标量运算时使用，步长 1 |
| useScalar | 使用标量 | Bool | false | - | - | 勾选：与标量运算；取消：与上一张缓存图运算 |

### 输入输出
- **输入**：当前图像；若 `useScalar=false` 还需上一帧缓存图作为第二操作数
- **输出**：`image`（运算结果，类型 Mat）——图像算术运算结果

### 使用示例
典型配置——背景相减提取运动目标：

```json
{
  "type": "ImageArithmetic",
  "params": {
    "operation": "subtract",
    "useScalar": false
  }
}
```

步骤说明：
1. 先用 ReadImage 加载背景图并送入缓存
2. 再加载/采集当前图像
3. ImageArithmetic 选 `subtract`，`useScalar=false`，输出即为目标差值图

### 注意事项
- 减法结果可能出现负值，底层会取绝对值或截断到 0，需根据实现确认
- `not` 运算不需要第二操作数，`useScalar` 无效
- 除法时 `scalar=0` 或除图为 0 会产生异常值，需避免

### 关联算子
- **ImageMerge**：用于图像拼接与 Alpha 混合
- **ScaleImage**：算术运算后常需缩放回有效动态范围
- **ColorDetect**：颜色掩膜通过 bitwise_and 应用到原图

## ImagePreprocess（图像预处理）

### 核心含义
一站式图像预处理算子，将去噪与形态学操作合并到一个算子中，避免在画布上放置多个独立算子。支持双边滤波去噪 + 形态学开/闭/腐蚀/膨胀的组合处理。

适用于需要快速组合基础预处理且不关心各步骤独立输出的场景，可简化流程图。

### 原理简述
- **denoise**（双边滤波）：调用 `cv::bilateralFilter`，固定参数 `d=9, sigmaColor=75, sigmaSpace=75`。双边滤波在平滑的同时保留边缘，适合保边去噪
- **morphology**：
  - `open`（开运算）：先腐蚀后膨胀，调用 `cv::morphologyEx(MORPH_OPEN)`
  - `close`（闭运算）：先膨胀后腐蚀，调用 `cv::morphologyEx(MORPH_CLOSE)`
  - `erode`（腐蚀）：调用 `cv::erode`
  - `dilate`（膨胀）：调用 `cv::dilate`

形态学结构元素尺寸由 `kernelSize` 决定，固定为矩形结构元。

### 适用场景
- 场景1：快速预处理组合——一次完成去噪 + 形态学，简化流程
- 场景2：噪声+小孔洞复合缺陷——先双边去噪再闭运算填孔
- 场景3：小白噪点去除——直接使用开运算模式

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| denoise | 双边滤波去噪 | Bool | false | - | - | 使用 cv::bilateralFilter，强度 d=9 / sigma=75 |
| morphology | 形态学操作 | Enum | none | none / open / close / erode / dilate | - | 开：去小白噪；闭：填小黑洞；腐蚀/膨胀：形态学基础 |
| kernelSize | 核大小 | Int | 3 | 1 ~ 31 | px | 形态学核尺寸（奇数，推荐 3-7），步长 2 |

### 输入输出
- **输入**：任意通道数的图像
- **输出**：`image`（预处理结果，类型 Mat）——预处理后的图像

### 使用示例
典型配置——双边去噪 + 闭运算填孔：

```json
{
  "type": "ImagePreprocess",
  "params": {
    "denoise": true,
    "morphology": "close",
    "kernelSize": 5
  }
}
```

### 注意事项
- 双边滤波参数固定，无法调整；如需自定义请使用独立滤波算子
- `morphology=none` 时只做去噪；`denoise=false` 且 `morphology=none` 时算子实际不处理
- 形态学结构元固定为矩形，圆形或十字形状需使用独立的 Closing / Opening 等算子

### 关联算子
- **Closing / Opening**：独立的形态学算子，支持圆形/十字形状
- **GaussFilter**：双边滤波的轻量替代
- **EdgeDetect**：预处理后通常进入边缘检测

## EdgeDetect（边缘检测）

### 核心含义
基于 Canny 算法检测图像中的边缘，输出二值化的边缘图。Canny 是最经典的边缘检测算法之一，结合了噪声抑制、梯度计算、双阈值筛选和边缘连接四个步骤，能在噪声环境下提取连续、单像素宽的边缘。

属于预处理分类，是目标轮廓提取、尺寸测量等任务的前置步骤。

### 原理简述
Canny 算法流程：
1. **高斯平滑**：用 5×5 高斯核去噪（内置）
2. **梯度计算**：用 Sobel 算子（`apertureSize` 控制 3/5/7）计算 x、y 方向梯度，得到梯度幅值与方向
3. **非极大值抑制**：沿梯度方向保留局部最大像素，细化边缘
4. **双阈值筛选**：高于 `highThreshold` 为强边缘，介于 `lowThreshold` 与 `highThreshold` 之间为弱边缘，低于 `lowThreshold` 被舍弃
5. **滞后连接**：弱边缘仅在与强边缘连通时保留

底层调用 `cv::Canny`。

### 适用场景
- 场景1：尺寸测量——提取目标轮廓用于亚像素边缘定位
- 场景2：目标分割——通过边缘图配合后续 Blob 分析
- 场景3：缺陷检测——裂纹、划痕等线性缺陷的提取

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| lowThreshold | 低阈值 | Int | 50 | 0 ~ 500 | - | Canny 低阈值，步长 10 |
| highThreshold | 高阈值 | Int | 150 | 0 ~ 500 | - | Canny 高阈值（建议为低阈值的 2-3 倍），步长 10 |
| apertureSize | Sobel 核 | Int | 3 | 3 ~ 7 | - | Sobel 算子核大小（3/5/7），步长 2 |

### 输入输出
- **输入**：单通道灰度图像（彩色图像需先转灰度）
- **输出**：`edges`（边缘图像，类型 Mat）——Canny 边缘检测结果（单通道二值图）

### 使用示例
典型配置——中等灵敏度边缘检测：

```json
{
  "type": "EdgeDetect",
  "params": {
    "lowThreshold": 50,
    "highThreshold": 150,
    "apertureSize": 3
  }
}
```

步骤说明：
1. 前置 GaussFilter 做轻度平滑去噪
2. EdgeDetect 设 `lowThreshold=50, highThreshold=150`（2-3 倍关系）
3. 输出二值边缘图，送入后续轮廓提取或 Blob 分析

### 注意事项
- `highThreshold` 建议为 `lowThreshold` 的 2-3 倍，过低会导致噪声边缘过多
- `apertureSize` 增大会增加计算量，且对噪声更敏感，一般保持 3
- 输入图像需为灰度图，彩色图应先转灰度（ReadImage 设 `colorMode=grayscale` 或前置 ChannelSplit）

### 关联算子
- **GaussFilter**：典型前置，去噪避免伪边缘
- **Emphasize**：锐化后边缘更显著，可降低阈值
- **ImagePreprocess**：可代替前置 GaussFilter + 形态学组合

## ColorDetect（颜色检测）

### 核心含义
在 HSV 颜色空间中通过阈值分割检测特定颜色目标，输出二值掩膜图。相比 RGB 颜色空间，HSV 将颜色信息（H）与亮度（V）和饱和度（S）分离，对光照变化更鲁棒，是工业颜色检测的常用方法。

属于增强与色彩子组，适用于需要按颜色区分目标的应用，如标签识别、彩色物料分拣、特定颜色缺陷标记等。

### 原理简述
处理流程：
1. 将输入 BGR 图像通过 `cv::cvtColor(COLOR_BGR2HSV)` 转换到 HSV 空间
2. 用 `cv::inRange` 按 `[hMin, hMax] / [sMin, sMax] / [vMin, vMax]` 三组阈值构造掩膜
3. 落在阈值范围内的像素置 255（前景），其余置 0（背景）

OpenCV 中 H 通道范围为 0-179（对应色环 0°-360°），S/V 范围为 0-255。`hMax=180` 表示不过滤色相。

### 适用场景
- 场景1：特定颜色目标定位——如红色标签、绿色 LED 灯
- 场景2：彩色物料分拣——按颜色区分不同物料
- 场景3：缺陷颜色标记——检测产品上的异色污点

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| hMin | 色相最小 | Int | 0 | 0 ~ 179 | - | HSV 颜色空间色相下界，步长 1 |
| hMax | 色相最大 | Int | 180 | 0 ~ 180 | - | HSV 颜色空间色相上界（OpenCV hue 范围 0-179，180 表示不过滤），步长 1 |
| sMin | 饱和度最小 | Int | 0 | 0 ~ 255 | - | 饱和度下界，步长 1 |
| sMax | 饱和度最大 | Int | 255 | 0 ~ 255 | - | 饱和度上界，步长 1 |
| vMin | 明度最小 | Int | 0 | 0 ~ 255 | - | 明度下界，步长 1 |
| vMax | 明度最大 | Int | 255 | 0 ~ 255 | - | 明度上界，步长 1 |

### 输入输出
- **输入**：BGR 三通道彩色图像
- **输出**：`mask`（颜色掩膜，类型 Mat）——颜色阈值检测结果（单通道二值图）

### 使用示例
典型配置——检测红色目标：

```json
{
  "type": "ColorDetect",
  "params": {
    "hMin": 0,
    "hMax": 10,
    "sMin": 100,
    "sMax": 255,
    "vMin": 100,
    "vMax": 255
  }
}
```

注意：红色在 HSV 色环 0° 附近，需分为 0-10 和 170-180 两段，可通过两次 ColorDetect + ImageArithmetic(or) 合并。

### 注意事项
- 输入必须为 BGR 三通道图，单通道灰度图无意义
- `sMin` 和 `vMin` 不宜过低，否则会误检白色/灰色区域
- 红色目标的 H 跨越 0°/360° 边界，需分段检测或使用色相偏移技巧

### 关联算子
- **RgbExtract / ChannelSplit**：用于分析原始颜色通道
- **ImageArithmetic**：合并多段颜色掩膜（or 运算）
- **ImagePreprocess**：掩膜后做开运算去除小噪点

## MedianImage（中值滤波）

### 核心含义
使用中值滤波器对图像进行平滑，将每个像素替换为其邻域窗口内像素的中位数。中值滤波对椒盐噪声（脉冲噪声）有极佳的抑制效果，且能较好保留边缘，是非线性滤波的代表。

属于空间滤波子组，与 GaussFilter / MeanImage 互补：高斯与均值适合高斯噪声，中值适合脉冲噪声。

### 原理简述
在 `kernelSize × kernelSize` 的方形窗口内，将所有像素值排序，取中位数作为中心像素的新值。底层调用 `cv::medianBlur`。

由于中值滤波不可分离，复杂度为 O(N·k²·log k)（含排序），大核时计算较慢。中值滤波对极端孤立点（椒盐噪声）非常敏感且能完全消除，但对分布性噪声（高斯）效果不如线性滤波。

### 适用场景
- 场景1：椒盐噪声去除——传感器传输错误导致的黑白点噪声
- 场景2：边缘保留平滑——需要平滑但不能模糊边缘的场景
- 场景3：二值图去噪——掩膜图中的小噪点清理

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| kernelSize | 滤波核大小 | Int | 5 | 1 ~ 51 | px | 中值核尺寸（奇数），步长 2 |

### 输入输出
- **输入**：任意通道数的图像（单通道或三通道）
- **输出**：`image`（滤波结果，类型 Mat）——中值滤波后的图像

### 使用示例
典型配置——5×5 中值滤波去除椒盐噪声：

```json
{
  "type": "MedianImage",
  "params": {
    "kernelSize": 5
  }
}
```

### 注意事项
- `kernelSize` 必须为正奇数
- 核越大计算越慢（不可分离），实时性要求高时建议 k≤7
- 对高斯噪声效果一般，应改用 GaussFilter

### 关联算子
- **GaussFilter**：高斯噪声场景的互补选择
- **MeanImage**：更快的线性平滑
- **ColorDetect**：掩膜图去噪的典型下游

## Histogram（直方图）

### 核心含义
计算并可视化图像的灰度分布直方图，输出一张 256×256 的直方图图像。支持三种模式：灰度直方图、三通道彩色直方图、均衡化后的灰度直方图。直方图是分析图像对比度、动态范围、光照分布的重要工具。

属于图像分析子组，通常用于参数调优阶段的诊断与验证，而非主流程的处理节点。

### 原理简述
- **gray** 模式：调用 `cv::calcHist` 计算单通道灰度分布，绘制为折线/柱状图
- **color** 模式：分别计算 B/G/R 三通道直方图，叠加显示
- **equalize** 模式：先调用 `cv::equalizeHist` 做直方图均衡化，再计算并显示均衡化后的灰度直方图

`bins` 控制直方图分组数，`rangeMin/rangeMax` 限定统计范围。

### 适用场景
- 场景1：曝光质量评估——观察灰度分布是否集中、是否过曝/欠曝
- 场景2：阈值选择参考——根据直方图双峰位置确定分割阈值
- 场景3：均衡化效果验证——对比均衡化前后直方图变化

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| mode | 模式 | Enum | gray | gray / color / equalize | - | 灰度 / 彩色 / 均衡化 |
| bins | bin 数量 | Int | 256 | 16 ~ 512 | - | 直方图 bin 数量（推荐 64/128/256），步长 16 |
| rangeMin | 范围下限 | Double | 0.0 | 0 ~ 255 | - | 统计范围下限，步长 1 |
| rangeMax | 范围上限 | Double | 256.0 | 1 ~ 256 | - | 统计范围上限，步长 1 |

### 输入输出
- **输入**：单通道或三通道图像（color 模式需三通道）
- **输出**：`image`（直方图图像，类型 Mat）——256x256 可视化直方图

### 使用示例
典型配置——查看灰度分布：

```json
{
  "type": "Histogram",
  "params": {
    "mode": "gray",
    "bins": 256,
    "rangeMin": 0.0,
    "rangeMax": 256.0
  }
}
```

### 注意事项
- `rangeMax` 上限为 256（独占上限），对应 8 位图像的 [0,255] 范围
- `color` 模式需要三通道输入，单通道图像会报错或无法显示彩色分布
- 均衡化模式仅对灰度图有效，彩色图应先转灰度

### 关联算子
- **ScaleImage**：根据直方图分布调整对比度
- **ReadImage**：通过 `colorMode=grayscale` 提供灰度输入
- **ChannelSplit**：分析单通道分布时配合使用

## RgbExtract（RGB通道提取）

### 核心含义
从 BGR 三通道图像中提取指定的 R、G 或 B 单通道，并将单通道结果转换为 BGR 三通道格式返回（三个通道值相同，便于直接显示）。这是简化的通道提取算子，仅支持 RGB 颜色空间。

属于通道操作子组，是 ChannelSplit 的轻量版本，适用于仅需 RGB 单通道的简单场景。

### 原理简述
底层调用 `cv::extractChannel` 提取指定通道（注意 OpenCV 默认顺序为 BGR，因此 R 通道索引为 2，G 为 1，B 为 0），然后通过 `cv::cvtColor(COLOR_GRAY2BGR)` 将单通道图扩展为三通道图，使每个像素的 B/G/R 值相同。

转换为三通道后可直接送入后续算子，无需关心通道数兼容性。

### 适用场景
- 场景1：单通道显示——提取 R 通道用于红色目标可视化
- 场景2：通道差异分析——分别提取 R/G/B 做通道间运算
- 场景3：简化流程——仅需 RGB 单通道且不需要 HSV/Lab 等其他空间

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| channel | 通道 | Enum | r | r / g / b | - | 待提取的通道：r=红, g=绿, b=蓝 |

### 输入输出
- **输入**：BGR 三通道彩色图像
- **输出**：`image`（通道图像，类型 Mat）——指定通道的图像（单通道转 BGR）

### 使用示例
典型配置——提取红色通道：

```json
{
  "type": "RgbExtract",
  "params": {
    "channel": "r"
  }
}
```

### 注意事项
- 输入必须为三通道 BGR 图，单通道图无意义
- 输出虽为三通道格式，但三通道值相同，本质仍是灰度信息
- 如需 HSV/Lab 等其他颜色空间的通道，应使用 ChannelSplit

### 关联算子
- **ChannelSplit**：支持 RGB/HSV/Lab/YUV 多种颜色空间的通道分离
- **ColorDetect**：颜色检测的替代方案，基于 HSV 阈值
- **ImageArithmetic**：可对提取的多个通道做差值运算

## ChannelSplit（通道分离）

### 核心含义
支持 RGB / HSV / Lab / YUV 四种颜色空间的通道分离，提取指定索引的单通道图像并转为 BGR 格式返回。相比 RgbExtract 仅支持 RGB，ChannelSplit 覆盖更广泛的色彩分析需求，特别是基于 HSV/Lab 的颜色检测场景。

属于通道操作子组，是颜色空间分析的通用工具。

### 原理简述
处理流程：
1. 根据 `colorSpace` 调用 `cv::cvtColor` 将 BGR 转换到目标颜色空间（RGB 无需转换，HSV 调用 `COLOR_BGR2HSV`，Lab 调用 `COLOR_BGR2Lab`，YUV 调用 `COLOR_BGR2YUV`）
2. 调用 `cv::extractChannel` 按 `channelIndex`（0/1/2）提取对应通道
3. 通过 `cv::cvtColor(COLOR_GRAY2BGR)` 转回三通道格式以便显示

各颜色空间通道含义：
- RGB: 0=R, 1=G, 2=B
- HSV: 0=H(色相), 1=S(饱和度), 2=V(明度)
- Lab: 0=L(亮度), 1=a(红绿), 2=b(黄蓝)
- YUV: 0=Y(亮度), 1=U, 2=V

### 适用场景
- 场景1：HSV 颜色分析——提取 H 通道用于颜色分割
- 场景2：Lab 亮度分离——提取 L 通道做亮度无关的处理
- 场景3：YUV 亮度/色度分离——提取 Y 通道做压缩域分析

### 参数详解
| 参数名 | 中文名 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|--------|--------|------|--------|------|------|------|
| colorSpace | 颜色空间 | Enum | RGB | RGB / HSV / LAB / YUV | - | 选择颜色空间：RGB/HSV/Lab/YUV |
| channelIndex | 通道索引 | Int | 0 | 0 ~ 2 | - | 通道索引：0/1/2（RGB: R/G/B, HSV: H/S/V, Lab: L/a/b, YUV: Y/U/V），步长 1 |

### 输入输出
- **输入**：BGR 三通道彩色图像
- **输出**：`image`（通道图像，类型 Mat）——指定通道的单通道图像（转 BGR 显示）

### 使用示例
典型配置——提取 HSV 的 S 通道（饱和度）：

```json
{
  "type": "ChannelSplit",
  "params": {
    "colorSpace": "HSV",
    "channelIndex": 1
  }
}
```

### 注意事项
- 输入必须为三通道 BGR 图，单通道或灰度图无意义
- `channelIndex` 范围为 0-2，超出范围会报错
- 输出为三通道 BGR 格式（三通道值相同），如需真正的单通道输出请在下游处理

### 关联算子
- **RgbExtract**：仅 RGB 空间的轻量替代
- **ColorDetect**：基于 HSV 阈值的颜色检测
- **ImageArithmetic**：可对多个通道做组合运算
