## 3. 图像列表功能增强

### 3.1 功能描述

在图像列表视图中，每一项元素左侧添加独立复选框，支持单个图像的选择与取消选择。

### 3.2 界面布局

```
┌─────────────────────────────────┐
│ [✓]  image1.jpg  [预览] [删除] │
│ [✗]  image2.jpg  [预览] [删除] │
│ [✓]  image3.jpg  [预览] [删除] │
│ [✗]  image4.jpg  [预览] [删除] │
└─────────────────────────────────┘
```

### 3.3 操作说明

#### 选择单个图像
1. 找到目标图像项
2. 点击左侧复选框
3. 复选框变为 ✓ 状态，表示已选中

#### 取消单个图像
1. 找到已选中的图像项
2. 点击左侧复选框
3. 复选框变为 ✗ 状态，表示已取消

### 3.4 技术特点

- **数据同步**：复选框状态与底层数据模型实时同步
- **性能优化**：状态更新时不会重建整个列表，响应快速
- **自适应布局**：在不同屏幕尺寸下均能正常显示和交互

## 4. 图片选择功能实现

### 4.1 功能描述

提供丰富的图片选择操作，包括全选、取消全选、反选，并支持 Ctrl 键多选。

### 4.2 界面布局

```
┌───────────────────────────────────────────────┐
│ [全选] [反选] [删除] [已选: 2/5]             │
├───────────────────────────────────────────────┤
│ [✓]  image1.jpg  [预览] [删除] │
│ [✓]  image2.jpg  [预览] [删除] │
│ [✗]  image3.jpg  [预览] [删除] │
│ [✗]  image4.jpg  [预览] [删除] │
│ [✗]  image5.jpg  [预览] [删除] │
└───────────────────────────────────────────────┘
```

### 4.3 操作说明

#### 全选所有图像
1. 点击「全选」按钮
2. 所有图像的复选框变为 ✓ 状态
3. 按钮文字自动变为「取消全选」

#### 取消全选
1. 点击「取消全选」按钮
2. 所有图像的复选框变为 ✗ 状态
3. 按钮文字自动恢复为「全选」

#### 反选
1. 点击「反选」按钮
2. 已选中的图像变为未选中
3. 未选中的图像变为选中
4. 例如：[✓✓✗✗✗] → [✗✗✓✓✓]

#### Ctrl 键多选
1. 按住键盘 Ctrl 键
2. 点击多个图像项
3. 可以实现不连续的多选

### 4.4 选择状态稳定性

- 选择状态在页面滚动时保持不变
- 图像加载后自动恢复之前的选择状态
- 筛选操作不会影响已选择的图像

## 5. 类别管理功能优化

### 5.1 功能描述

在每个类别名称右侧添加视觉清晰的"加入类别"按钮，支持将选中的图片批量添加到指定类别。

### 5.2 界面布局

```
┌───────────────────────────────────────┐
│ 类别列表                              │
├───────────────────────────────────────┤
│ 正常品 [加入]                     │
│ 划痕缺陷 [加入]                   │
│ 裂纹缺陷 [加入]                   │
│ 污渍缺陷 [加入]                   │
│ 变形缺陷 [加入]                   │
└───────────────────────────────────────┘
```

### 5.3 操作说明

#### 步骤 1：选择图片
1. 在图像列表中使用复选框选择要添加的图片
2. 至少需要选择 1 张图片

#### 步骤 2：点击"加入"按钮
1. 在类别列表中找到目标类别
2. 点击该类别右侧的「加入」按钮
3. 按钮状态说明：
   - **灰色**：不可点击（无图片选中）
   - **蓝色**：可点击（有图片选中）

#### 步骤 3：确认添加
1. 系统弹出确认对话框
2. 显示即将添加的图片数量和目标类别
3. 点击「确认」完成添加

#### 步骤 4：查看结果
1. 操作成功后显示成功提示
2. 可以在类别详情中查看已添加的图片

### 5.4 视觉反馈

- **成功提示**：绿色对话框，显示"成功添加 X 张图片到类别 Y"
- **失败提示**：红色对话框，显示具体错误原因
- **按钮状态**：自动根据选择状态更新可用性

## 6. 模型选择功能配置

### 6.1 功能描述

模型选择下拉菜单默认选中 YOLO 模型，无需用户额外操作。

### 6.2 界面布局

```
┌───────────────────────────────────────┐
│ 模型选择                              │
├───────────────────────────────────────┤
│ ┌───────────────────────────────┐   │
│ │ ▼ yolov5s（默认）          │   │
│ └───────────────────────────────┘   │
│                                       │
│ [加载模型] [开始推理] [停止推理]    │
│                                       │
│ 模型信息：                            │
│ • 模型名称：yolov5s                  │
│ • 输入尺寸：640×640                  │
│ • 推理引擎：ONNX Runtime             │
└───────────────────────────────────────┘
```

### 6.3 操作说明

#### 查看可用模型
1. 点击下拉菜单
2. 显示所有可用的模型列表：
   - yolov5s（YOLO 目标检测）
   - resnet50（ResNet 图像分类）
   - defect_detector（缺陷检测专用）

#### 选择其他模型
1. 点击下拉菜单
2. 从列表中选择需要的模型
3. 模型信息自动更新显示

#### 默认模型选择
- 首次打开训练推理模块时，自动选择 YOLO 模型
- 刷新页面或重新加载模块时，保持 YOLO 模型选中状态
- YOLO 模型可直接用于推理，无需用户额外配置

### 6.4 智能匹配逻辑

系统按照以下优先级选择默认模型：

1. 优先查找完全匹配 "YOLO" 的模型
2. 如果没找到，查找包含 "yolo" 的模型（不区分大小写）
3. 如果还没找到，选择列表中的第一个模型
4. 如果没有模型，显示提示信息

## 7. 完整操作流程

### 7.1 批量标注数据流程

   ↓

## 8. 常见问题

### Q1：复选框点击没有反应？

**原因**：可能是列表正在刷新或数据正在加载。

**解决方案**：
1. 等待列表加载完成后再操作
2. 检查是否有图片正在处理中

### Q2："加入"按钮是灰色的，点击不了？

**原因**：没有选择任何图片。

**解决方案**：
1. 在图像列表中至少选择 1 张图片
2. 确认复选框状态为 ✓
3. 按钮会自动变为蓝色可点击状态

### Q3：YOLO 模型没有在列表中显示？

**原因**：模型文件可能不存在或路径配置错误。

**解决方案**：
1. 检查 `models/` 目录下是否存在 YOLO 模型文件
2. 确认文件格式为 ONNX（.onnx）
3. 查看系统日志获取详细错误信息

### Q4：选择状态在滚动后消失了？

**原因**：旧版本可能存在此问题，新版本已修复。

**解决方案**：
1. 更新到最新版本
2. 确认选择状态已正确保存到数据模型

### Q5：反选功能如何使用？

**操作示例**：
假设当前状态：[✓✓✗✗✗]（选中前 2 张）

1. 点击「反选」按钮
2. 结果变为：[✗✗✓✓✓]（选中后 3 张）
3. 再点击一次「反选」恢复原始状态

### Q6：如何快速选择所有图片？

**方式 1**：点击「全选」按钮

**方式 2**：按住 Shift 键点击第一个和最后一个

### Q7：添加到类别后，在哪里查看？

**查看位置**：
1. 在类别列表中点击该类别
2. 右侧显示该类别下的所有图片
3. 可以查看、删除或移动图片

### Q8：默认模型可以修改吗？

**答案**：可以。

**修改方式**：
1. 从下拉菜单中选择其他模型
2. 系统会记住您的选择
3. 但重启程序后会恢复为 YOLO 默认
