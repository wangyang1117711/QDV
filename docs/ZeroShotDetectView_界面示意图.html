模型注意事项

MobileSAM

轻量分割模型，支持编码器 + 解码器拆分结构（点提示 → 掩码）。

注意事项

  • 推荐输入尺寸 1024×1024
  • 输入图像需归一化到 [0,1]
  • 编码器 + 解码器需同目录
  • 点提示驱动掩码生成

输入格式

  • JPG / PNG / BMP / TIFF / WEBP
  • 最大文件 50MB
  • 最小尺寸 32×32

限制条件

  • 不支持中文文件路径（已通过 QFile 规避）
  • 对纹理类异常检测效果有限
  • 需预先准备 mobile_sam_encoder.onnx

使用建议

  • 启用量化可降低内存 70%
  • 多次推理取稳定值可减少抖动
  • 异常阈值建议从 0.5 起调
  • 可与 PatchCore 渐进式切换
