## 1. 启动流程概述

Q-DetectVision的启动流程包含以下核心阶段：

```
启动程序 → 初始化日志系统 → 初始化核心服务 → 创建主窗口 → 显示登录界面 → 等待用户操作
```

### 启动流程图

```
┌─────────────────────────────────────────────────────────────┐
│                    启动程序 (main.cpp)                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  初始化日志系统 (Logger)                    │
│  - 创建日志目录 ./logs/                                    │
│  - 生成日志文件 yyyyMMdd.log                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  初始化认证服务 (AuthService)               │
│  - 加载用户凭证（SHA256哈希存储）                           │
│  - 初始化默认用户 admin/admin123                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                初始化方案管理器 (SchemeManager)              │
│  - 加载已保存的检测方案                                     │
│  - 初始化工具链执行器                                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                初始化结果数据库 (ResultDatabase)             │
│  - 创建/打开 SQLite 数据库                                 │
│  - 确保数据表存在                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                初始化视觉工具工厂 (ToolFactory)             │
│  - 注册所有视觉工具类型                                     │
│  - 加载工具元数据                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      创建主窗口                            │
│  - MainWindow 初始化                                       │
│  - LoginView 显示                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    启动完成，等待用户操作                    │
└─────────────────────────────────────────────────────────────┘
```

## 2. 初始化步骤详解

### 2.1 日志系统初始化

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 创建 `./logs/` 目录 | 目录创建成功或已存在 |
| 2 | 生成日志文件名 `yyyyMMdd.log` | 文件名格式正确 |
| 3 | 初始化 spdlog 日志器 | 日志系统可用 |

### 2.2 认证服务初始化

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 获取 AuthService 单例 | 返回非空指针 |
| 2 | 初始化默认用户 | admin 用户创建成功 |
| 3 | 验证密码哈希 | SHA256 哈希正确 |

### 2.3 方案管理器初始化

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 获取 SchemeManager 单例 | 返回非空指针 |
| 2 | 加载方案目录 | 无异常 |
| 3 | 初始化工具链执行器 | 执行器可用 |

### 2.4 结果数据库初始化

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 创建 `./data/` 目录 | 目录创建成功或已存在 |
| 2 | 打开数据库 `qdv_results.db` | 数据库连接成功 |
| 3 | 创建数据表（如不存在） | 表创建成功 |
| 4 | 查询记录数 | 返回正确数量 |

### 2.5 视觉工具工厂初始化

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 获取 ToolFactory 单例 | 返回非空指针 |
| 2 | 注册工具类型 | 所有工具注册成功 |
| 3 | 获取可用工具列表 | 返回工具类型列表 |

## 5. 常见启动问题

### 5.1 问题排查表

| 问题现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 程序无法启动 | Qt环境未配置 | 安装Qt6并配置环境变量 |
| 日志目录创建失败 | 权限不足 | 检查目录权限 |
| 数据库连接失败 | SQLite3未安装 | 安装SQLite3依赖 |
| 认证服务初始化失败 | 配置文件缺失 | 检查配置文件路径 |
| UI界面不显示 | QML文件缺失 | 检查资源文件 |

### 5.2 错误码说明

| 错误码 | 含义 |
|--------|------|
| -1 | 认证服务初始化失败 |
| -2 | 方案管理器初始化失败 |
| -3 | 数据库初始化失败 |
| -4 | 视觉工具工厂初始化失败 |
