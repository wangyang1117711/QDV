高斯滤波
GaussianSmooth
核心含义
对图像进行高斯低通滤波，抑制高频噪声与细节，实现整体平滑。
适用场景
去噪预处理、下采样前抗混叠、边缘检测前平滑。
功能描述
使用指定大小的二维高斯核与图像做卷积，核大小越大平滑越强。
参数详解
kernelSize· 核大小Int
默认: 3范围: [1, 31]
高斯核边长，须为正奇数；越大平滑越强。
sigma· 标准差Double
默认: 1.0范围: [0, 10]单位: px
高斯分布标准差；为 0 时由核大小自动推算。
注意事项
!核大小必须为正奇数，否则算子将报错。
!sigma 过大会导致图像过度模糊，丢失边缘信息。
